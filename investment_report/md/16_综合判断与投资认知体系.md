## 16.2 最终回答：如果今天重建一支专注中国具身智能的 VC 团队

### 一、应该如何理解这个产业（五句话）

1. **这是一个"硬件制造业 + AI 软件 + 场景服务"的复合产业，不是 AI 软件产业**。它的经济规律更接近汽车与工业自动化：学习曲线、可靠性工程、渠道和服务网络，而不是互联网的边际成本为零。
2. **当前市场是"研究工具、展示与政策项目"市场，劳动替代市场尚未形成**（T01）。
3. **行业的核心瓶颈已经从"智能"迁移到"可靠性与系统工程"**（T04），决定商业化距离的是接管率、看护配比、MTBF 和吞吐率，而不是模型参数量。
4. **中国的长期优势是"制造+场景"**，资本和政策是周期性的放大器（第十篇）。
5. **2026 年下半年起进入"商业验证期"**，收入质量会取代技术叙事，成为定价锚（T02）。

### 二、团队配置与研究重点

| 角色 | 职责 | 为什么需要 |
|---|---|---|
| 产业工程合伙人（汽车或工业自动化背景） | 硬件、可靠性、量产与供应链尽调 | 瓶颈已经迁移到系统工程 |
| 技术研究员（机器人学习背景） | 演示核验、模型与数据评估 | 识破演示与部署之间的鸿沟 |
| 场景研究员（制造、物流、能源行业） | 客户访谈、TCO 建模 | 用 ROI 而不是叙事来定价 |
| 财务与法务 | 收入质量、订单瀑布、关联方、条款 | 识别注水与关联交易 |
| 数据与投后 | 前置指标看板、组合监测 | 动态修正判断 |

**研究重点（按优先级）**：

1. 场景 TCO 与客户访谈库（每季度更新）；
2. 精密部件的良率、寿命与价格曲线；
3. 订单与收入质量数据库；
4. 第三方评测与部署指标；
5. 二级市场可比估值；
6. 政策与地缘追踪。

### 三、投什么、避什么

| 投 | 避 |
|---|---|
| 任务闭环的场景公司（形态中立） | 同质化双足整机新项目 |
| 有工艺壁垒、多客户、存量业务托底的精密部件 | 只有人形概念收入的部件公司 |
| 特种作业 | 文娱租赁与商演 |
| 国产端侧计算和工具链（已有头部定点） | 无生态的芯片初创 |
| 估值重置后的头部平台（结构化条款） | 估值/收入超过 50 倍、没有下行保护的后期轮 |
| 早期、低估值、有数据闭环证据的模型团队 | 估值 100 亿元以上、没有第三方付费的纯模型公司 |
| 可靠性、运维与车队管理软件 | 数据代采外包 |

### 四、未来三年的动态调整

| 时间 | 基准情景下的动作 | 若乐观触发 | 若悲观触发 |
|---|---|---|---|
| 2026Q4–2027H1 | 建库与深度尽调；投资场景闭环与精密部件；为头部预留重置额度 | 提前参与头部轮次（要求条款） | 暂停整机，加大部件与特种 |
| 2027H2–2028 | 跟踪物流与 3C 回本证据，加码复购明确的场景公司；参与并购整合 | 头部配置上调到 35% | 寻找不良资产并购机会，把投后管理放在首位 |
| 2029 起 | 布局标准化部件、运维金融、OS 和车队管理 | 平台生态投资 | 集中于已盈利资产 |
