# 第 27 章 蚂蚁集团·灵波科技（Robbyant）：后来者的"全栈开源"突袭——LingBot 系列

> **一句话定位**：蚂蚁集团的具身智能子公司**灵波科技（Robbyant）**是 2026 年中国具身领域最大的"黑马"之一。它在 2026 年 1 月下旬的"具身进化周"中**一口气开源了三款基座模型**——高精度空间感知模型 **LingBot-Depth**、基于 2 万小时真机数据的 **LingBot-VLA**、可实时交互的世界模型 **LingBot-World**；7 月又发布 **LingBot-VLA 2.0**（6 万小时真机数据、覆盖 17 家厂商 20 多种构型）与 **LingBot-World 2.0**（720p/60fps 连续生成长达约一小时）。灵波的路线可以概括为"**深度感知 + 大规模真机数据 VLA + 交互式世界模型**"三位一体、全部开源——以一种"后来者全栈突袭"的姿态，直接对标 π0.5 与 NVIDIA Cosmos。

## 1. 故事的开端：一家金融科技集团为什么做机器人？

蚂蚁集团做具身智能，乍看令人意外。但从蚂蚁的技术积累看，有其逻辑：
- **大模型能力**：蚂蚁自研了百灵（Ling）系列大模型（LingBot 的命名即来源于此）；
- **场景**：支付、生活服务、医疗健康（蚂蚁旗下的医疗与养老服务）等线下场景，对服务型机器人有潜在需求；
- **资本与耐心**：具身智能需要长周期投入，蚂蚁有能力进行"全栈布局"。

灵波的策略是"**后发先至**"：不在 VLA 赛道的早期与 PI、字节等正面竞争，而是在 2026 年以**一次性开源三款基座模型**的方式进入，并迅速以"超越 π0.5"的评测结果建立声誉。

## 2. 代表作一：LingBot-VLA 1.0 → 2.0——大规模多构型真机数据的 VLA

### 2.1 LingBot-VLA 1.0（2026.01）

| 维度 | 内容 |
|---|---|
| 预训练数据 | 约 **2 万小时**多构型真机数据 |
| 本体覆盖 | **9 种**主流双臂机器人构型 |
| 迁移效率 | 据称仅需约 **150 条**演示即可高质量迁移到新任务 |
| 训练效率 | 训练效率为主流框架的 **1.5–2.8 倍**（官方口径）|
| 开源 | 代码 GitHub，权重 Hugging Face / ModelScope |

**评测**：
- **GM-100**（上海交通大学开源的 100 项真实操作任务基准）：在 3 个不同的真实机器人平台上，跨本体泛化平均成功率从 π0.5 的 **13.0%** 提升到 **15.7%**（不使用深度）；加入深度信息后达到 **17.3%**；
- **RoboTwin 2.0**（50 项任务）：相比 π0.5 的操作成功率提升约 **9.92%**。

**解读**：GM-100 上的绝对成功率（13%–17%）非常低——这恰恰说明了**跨本体零样本泛化在 2026 年初仍是极难的问题**。灵波的贡献在于：在同一困难基准上相对 π0.5 有可测量的提升，并且**深度信息（LingBot-Depth）带来了额外收益**。

### 2.2 LingBot-VLA 2.0（2026.07.08）

| 维度 | 1.0 | **2.0** |
|---|---|---|
| 预训练真机数据 | 约 2 万小时 | **约 6 万小时** |
| 覆盖构型 | 9 种双臂 | **17 家厂商、20 多种构型** |
| 自由度 | 双臂 | **扩展头部、腰部、末端执行器与移动底盘**的自由度支持 |
| 深度 | 可选 | **默认融合 LingBot-Depth** |
| 能力 | 桌面双臂操作 | 新增**移动操作**等 |
| 推理 | — | 高效后训练版本在 **RTX 4090 上推理耗时可控制在 130 毫秒以内** |

**6 万小时意味着什么**：这是 2026 年中公开的、**以机器人本体数据为主**的开源 VLA 预训练规模中最大的之一（对比：π0 约 1 万小时、AgiBot World 约 3000 小时、LingBot 1.0 约 2 万小时）。注意它与 Generalist（50 万小时+）的区别：Generalist 主要是人类交互数据，而 LingBot-VLA 2.0 强调的是**多品牌、多构型的真实机器人数据**。

**"17 家厂商、20 多种构型"的生态意义**：灵波通过与大量本体厂商合作收集数据、并让模型原生支持这些构型，实际上在构建一个"**开源跨本体大脑 + 本体厂商联盟**"的生态——这与 NVIDIA GR00T（本体专属编解码器）、Gemini Robotics（Motion Transfer）的跨本体思路一致，但以开源方式推进。

（注：截至检索时，公开报道未明确披露 LingBot-VLA 的 VLM 底座与动作生成方式的细节，技术报告见 GitHub 仓库 lingbot-vla-v2，本章不做推测。）

## 3. 代表作二：LingBot-World 1.0 → 2.0——开源的实时交互世界模型

### 3.1 LingBot-World 1.0（2026.01.28–29）

> 技术报告：*Advancing Open-source World Models*（arXiv 2601.20540，2026-01-28）；Business Wire 新闻稿（2026-01-29）。

**定位**：一个"**源自视频生成的开源世界模拟器**"，面向具身智能、自动驾驶与游戏开发。

**技术底座与训练**：
- 代码库**基于阿里通义 Wan2.2**（约 14B 的图生视频扩散主干）构建——又一个"阿里底座被广泛采用"的例子（参见第 26 章）；
- **多阶段训练**：以 Wan2.2 为起点预训练 → 中期训练 → 后训练为**因果自回归生成**——把"被动的视频合成"改造为"**可交互、因果一致的世界模拟**"；
- **可扩展数据引擎**：覆盖数据获取、画像（profiling）与描述标注，支撑动作条件化训练。

**能力**：
- 从**一张真实世界图像或游戏截图**出发，生成**可交互的视频流**，无需针对特定场景训练；
- 生成吞吐约 **16 FPS**，端到端交互延迟 **小于 1 秒**；
- 可实现近 **10 分钟**连续稳定的生成（据报道）；
- 提供 **Base（Cam，相机位姿条件化）**、**Base（Act，动作条件化）** 与 **Fast** 加速版，各有 480P 与 720P 两种分辨率（二手资料称 Fast 版在 A100 级 GPU 上 480P 约 16 FPS、每帧约 62 毫秒）；
- **Apache-2.0** 许可。

**与 Genie 3 的对比**：Google DeepMind 的 Genie 3（2025.08）是同类"实时交互世界模型"的标杆（720p、24fps、数分钟一致性），但闭源。LingBot-World 以**开源**方式提供了类似能力，是中国开源世界模型的代表之一。

### 3.2 LingBot-World 2.0（2026.07）

- 支持**以 720p、60fps 连续生成长达约一小时**；
- 采用**因果预训练**方法与一种称为 **MoBA（Mask of Bidirectional Attention）** 的机制；
- 支持**多用户共享一个持久世界**；
- 首日即支持 **SGLang** 推理框架；
- 支持更多动作与事件（据报道）。

### 3.3 世界模型在灵波体系中的角色

在具身场景中，LingBot-World 可以承担：
1. **策略评估器**：在世界模型中闭环测试 LingBot-VLA，替代部分真机评测；
2. **数据生成器**：生成多样化场景，扩充训练数据；
3. **强化学习训练场**：在可交互的世界模型中进行 RL。

这与 1X（世界模型评估）、特斯拉（神经世界模拟器）、它石 AWE 3.5（在模型内部世界中 RL）的思路一致。

## 4. 代表作三：LingBot-Depth——具身的"深度眼睛"

LingBot-Depth 是灵波在"具身进化周"中发布的**高精度空间感知模型**，用于为机器人提供精确的深度信息。公开技术细节较少，但从其在体系中的作用可以看出其价值：
- 在 LingBot-VLA 1.0 的 GM-100 评测中，**加入深度信息使跨本体平均成功率从 15.7% 提升到 17.3%**；
- 在 LingBot-VLA 2.0 中被**默认融合**。

**为什么深度重要**：多数 VLA 只使用 RGB 图像，依赖模型从 2D 图像中"猜"深度；而精细操作（抓取、插入、放置）对三维位置精度极其敏感。这与智源 RoboBrain 2.5 强调"3D 度量空间推理"、HF LeRobot v0.6 加入"深度数据支持"属于同一趋势：**2026 年，具身大脑正在从"2D 看图"走向"3D 度量"**。

## 5. 技术路线总结：三位一体

```
       ┌──────────────────────────┐
       │   LingBot-Depth（感知）    │  ← 精确 3D 深度
       └─────────────┬────────────┘
                     │ 默认融合
                     ▼
       ┌──────────────────────────┐
       │   LingBot-VLA（执行）      │  ← 6 万小时多构型真机数据
       │   1.0 → 2.0               │     17 家厂商、20+ 构型
       └─────────────┬────────────┘
                     │ 评估 / 数据 / RL
                     ▼
       ┌──────────────────────────┐
       │   LingBot-World（想象）    │  ← 开源实时交互世界模型
       │   1.0 → 2.0               │     720p/60fps，约一小时
       └──────────────────────────┘
```

灵波的特色：**感知、执行、想象三个基座同时开源，且版本节奏整齐（1 月 1.0、7 月 2.0）**——这是一种以"开源生态"换取影响力与合作伙伴数据的策略。

## 7. 未来展望与风险

**展望**：
1. **数据联盟**：若持续扩大与本体厂商的合作，LingBot-VLA 的数据规模可能继续快速增长；
2. **世界模型 + VLA 闭环**：用 LingBot-World 做 VLA 的大规模评估与 RL，可能形成独特的"仿真-真实"迭代体系；
3. **蚂蚁的场景**：医疗、养老、生活服务等场景可能成为灵波模型的首批落地方向。

**风险**：
1. **评测的绝对水平**：GM-100 上 15%–17% 的成功率说明跨本体泛化仍很初级，开源模型的实用性需要更多真实部署验证；
2. **商业模式**：全面开源的商业回报路径尚不清晰；
3. **竞争激烈**：同时面对阿里、字节、智元、宇树等的开源模型竞争。
