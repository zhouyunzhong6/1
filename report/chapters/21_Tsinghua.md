# 第 21 章 清华大学：中国具身智能的"母港"——从 RDT 到 RDT2，与一支创业"清华帮"

> **一句话定位**：清华是中国具身智能最重要的学术源头与人才母港。朱军教授团队（TSAIL）的 **RDT-1B（2024.10，ICLR 2025）** 是当时全球最大的开源扩散式双臂操作基础模型；与生数科技合作的 **Vidar（2025.07）** 是"视频扩散模型作为机器人基座"路线的早期代表；**RDT2（2026.02）** 用超过 1 万小时的 UMI 式数据探索"零样本跨本体泛化"的极限。与此同时，清华交叉信息研究院（姚班体系）的年轻教授们创办或参与创办了星动纪元（陈建宇）、星海图（赵行、许华哲）、千寻智能（高阳）等一批头部具身公司——形成了中国具身智能独特的"**清华帮**"现象。

## 1. 故事的开端：扩散模型专家进入机器人

朱军教授是国内概率机器学习与扩散模型领域的权威——他的团队提出了 DPM-Solver（扩散模型快速采样器，被 Stable Diffusion 等广泛采用）、U-ViT（扩散 Transformer 的早期架构之一），并孵化了视频生成公司**生数科技**（Vidu）。

2024 年，当 Diffusion Policy 与 Octo 证明了"扩散模型生成动作"的威力后，朱军团队判断：**机器人动作生成本质上是一个高维、多模态的生成问题，正是扩散模型的主场**。他们要做的，是把"扩散 Transformer 的规模化经验"带到机器人领域。

## 2. 代表作一：RDT-1B（2024.10，ICLR 2025）——十亿参数的双臂扩散基础模型

> 论文：Songming Liu, Lingxuan Wu, Bangguo Li, Hengkai Tan, Huayu Chen, Zhengyi Wang, Ke Xu, Hang Su, Jun Zhu，*RDT-1B: a Diffusion Foundation Model for Bimanual Manipulation*（arXiv 2410.07864，ICLR 2025）；项目页 rdt-robotics.github.io

### 2.1 要解决的问题

双臂操作（倒水、交接、折叠）的难点是：**动作空间维度高、动作分布高度多模态、而双臂数据极其稀缺**。单一实验室的双臂数据往往只有几千条，训练不出通用模型；而大规模的 OXE 数据又大多是单臂、动作空间五花八门。

### 2.2 两个核心设计

**（1）物理可解释的统一动作空间（Physically Interpretable Unified Action Space）**

不同机器人的动作格式各异：有的输出关节角，有的输出末端位姿；有的是单臂 7 维，有的是双臂 14 维；有的还带移动底盘。RDT 设计了一个 **128 维**的统一空间：
- 每个维度都有**明确的物理含义**（例如"右臂关节 1 位置""左臂末端 x 坐标""底盘线速度"）；
- 每个机器人只填充它拥有的那些维度，其余用掩码标记；
- 这样，**不同机器人上"同一物理量"的数据会被映射到同一维度**，模型可以跨本体共享物理知识（区别于 π0 的"零填充到 18 维"——π0 的维度不保证物理对应）。

**（2）为机器人改造的扩散 Transformer（RDT）**

| 组件 | 设计 |
|---|---|
| 视觉编码器 | SigLIP（冻结），多路相机图像 |
| 语言编码器 | T5-XXL（冻结）|
| 主干 | 扩散 Transformer，约 **12 亿参数** |
| 条件注入 | **交替交叉注意力**：奇偶层分别注意图像 token 与语言 token，避免某一模态（图像 token 远多于语言 token）淹没另一模态 |
| 归一化 | 引入 QKNorm 与 RMSNorm，应对机器人物理量数值范围大、易导致训练不稳定的问题 |
| 输出 | 用**非线性 MLP 解码器**替代线性头，更好地拟合非线性的机器人动力学；一次生成多步动作块 |

### 2.3 数据与训练

- **预训练**：在当时规模最大的多机器人数据集合上预训练（论文报告约 46 个数据集、超过 100 万条轨迹，包括 OXE、DROID 等）；
- **微调**：团队自采了 **6000+ 条**双臂示范（在松灵 Cobot Magic / ALOHA 式双臂平台上），覆盖 300 多种任务，是当时最大的双臂数据集之一。

### 2.4 结果

- **零样本泛化**：对未见过的物体、场景具有泛化能力；
- **指令跟随**：能理解并区分细粒度指令（例如"倒三分之一杯水"vs"倒满"）；
- **少样本学习**：只需 **1–5 条示范**就能学会新技能（例如折叠短裤、遥控机器狗的手柄操作）；
- 在灵巧双臂任务上显著优于 OpenVLA、Octo、ACT 等基线。

### 2.5 意义

RDT-1B 是**中国团队较早发布、在国际上被广泛使用的开源机器人基础模型之一**（开源代码与权重），也是"扩散 Transformer 规模化"在机器人领域的标志性工作。它提出的"物理可解释统一动作空间"被许多后续跨本体模型借鉴。

## 3. 代表作二：Vidar（2025.07）——视频扩散模型作为机器人基座

> 论文：*Vidar: Embodied Video Diffusion Model for Generalist (Bimanual) Manipulation*（清华大学 × 生数科技，arXiv 2507.12898，2025.07 首发，2025.09/12 修订）

### 3.1 思路：先"想象"，再"反推"

Vidar 是"**世界模型（视频生成）→ 动作**"路线在中国的早期代表作，与 1X 的 1XWM、NVIDIA 的 DreamGen 思路相通：

```
   当前多视角画面 + 语言指令
              │
              ▼
   ┌───────────────────────────────────┐
   │ 具身视频扩散模型（互联网规模视频预训练    │
   │ → 75 万条多视角机器人轨迹继续预训练）     │
   │ → 生成"机器人完成任务"的未来视频         │
   └───────────────────────────────────┘
              │
              ▼
   ┌───────────────────────────────────┐
   │ 掩码逆动力学模型（MIDM）               │
   │ · 自动学习"关注机械臂区域"的掩码         │
   │ · 从生成视频中提取机器人动作             │
   └───────────────────────────────────┘
              │
              ▼
          机器人执行
```

### 3.2 两个关键设计

1. **统一观察空间**：把**机器人、相机、任务与场景上下文**统一编码为条件，使视频模型能在多平台的大规模具身视频上联合预训练——论文使用了来自 **3 个真实机器人平台的约 75 万条多视角轨迹**进行具身领域的继续预训练；
2. **掩码逆动力学模型（MIDM）**：传统 IDM 容易被背景中无关的变化干扰（例如光线、其他物体移动）。MIDM 自动学习一个**只关注机器人手臂区域的掩码**，从而在新背景、新场景中更鲁棒地提取动作——不需要人工标注掩码。

### 3.3 结果

论文报告：
- 在**一个未见过的机器人**上，仅用约 **20 分钟**人类示范（约为常规数据量的 1%）进行适配，Vidar 即优于当时的最优基线，并能泛化到**未见过的任务、背景与相机布局**；
- 在 **RoboTwin** 基准的困难多任务设置下取得最优表现；
- **测试时扩展（test-time scaling）**：推理时生成多个候选未来视频，再从中挑选最合适的一个——把 LLM 领域"多采样再选择"的思想用到了视频策略上。

（作者包括 Yao Feng、Hengkai Tan 等；生数科技为合作方。检索中未能确认论文是否明确以 Vidu 为基础模型，本章不作断言。）

### 3.4 意义

Vidar 让"**视频大模型公司（生数）+ 机器人学术团队（清华）**"的组合成为现实，是 2025–2026 年中国"世界模型派"（极佳 GigaWorld、蚂蚁 LingBot-World、智元 Genie Envisioner、自变量 WALL-B）兴起的重要先声之一。

## 4. 代表作三：RDT2（2026.02）——UMI 数据的缩放极限与零样本跨本体

> 论文：Songming Liu, ..., Jun Zhu 等，*RDT2: Exploring the Scaling Limit of UMI Data Towards Zero-Shot Cross-Embodiment Generalization*（arXiv 2602.03310，2026-02-03）；项目页 rdt-robotics.github.io/rdt2

### 4.1 问题：能否"零样本"换一台机器人？

RDT-1B 实现了"少样本"学习新技能，但换到一台**全新的机器人**上，仍需要在该机器人上采集数据微调。RDT2 追问：**如果训练数据本身就与机器人无关（UMI 式手持采集），能否训练出一个在新机器人上零样本工作的模型？**

### 4.2 数据：超过 1 万小时的增强版 UMI 数据

- 团队使用**增强版 UMI**（手持夹爪采集装置，见第 11 章）采集了**超过 10,000 小时**的演示数据；
- 据综述，这些数据来自 **100 多个家庭环境**——这与 π0.5"约 100 个家庭"的环境多样性量级相当，但采集方式不需要机器人；
- 这是 2026 年初公开报道中规模最大的 UMI 式数据之一。

### 4.3 模型：7B VLM + RVQ + 流匹配 + 蒸馏

| 组件 | 设计 |
|---|---|
| 主干 | 约 **70 亿参数**的视觉语言模型 |
| 动作表示 | **残差向量量化（RVQ）**：把连续动作压缩为离散 token，便于 VLM 以语言建模方式学习（思路类似 FAST，但用学习式量化）|
| 动作生成 | **流匹配**：生成连续、精确的动作 |
| 实时化 | **蒸馏**：把多步生成蒸馏为少步，满足实时推理 |

这一"离散 token 预训练 + 流匹配连续生成 + 蒸馏加速"的组合，与 PI 的 π0.5/KI 思想同源，可以看作中国团队对"VLA 训练配方"的独立实现与扩展。

### 4.4 结果

RDT2 被描述为**最早同时对未见过的物体、场景、指令乃至机器人平台实现零样本泛化的模型之一**：在训练中从未见过的机器人上，只需与 UMI 相同的腕部相机配置，即可直接执行开放词汇的操作任务。

### 4.5 意义

RDT2 是"**无本体数据 + 大 VLM**"路线的重要学术证据，与 Generalist（人类交互数据缩放）、Sunday（手套）、它石（人类数据）共同构成 2026 年"人类/手持数据派"的主张。它的开源属性使这条路线可以被学术界验证。

## 6. 横向对比与身位

| 维度 | 清华（RDT 系列）| 斯坦福（OpenVLA）| Berkeley（Octo）|
|---|---|---|---|
| 首个代表模型 | RDT-1B（12 亿，扩散 DiT）| OpenVLA（70 亿，离散 token）| Octo（9300 万，扩散头）|
| 动作空间 | 128 维物理可解释统一空间 | 7 维离散 | 模块化动作头 |
| 后续演进 | RDT2（7B + RVQ + 流匹配 + UMI 1 万小时）| OFT（并行解码 + 连续动作）| CrossFormer（跨 20+ 本体）|
| 产业孵化 | 生数（视频）、IIIS 系创业公司 | PI、Sunday | PI、Covariant |

**身位**：清华在**中国具身学术界处于绝对领先地位**，在全球范围内与斯坦福、Berkeley、CMU 处于同一梯队；其"学术 + 创业"的转化效率在全球高校中极为突出。
