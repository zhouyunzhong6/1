# 第 24 章 北京智源人工智能研究院（BAAI）：专注"具身大脑"的推理模型与跨本体操作系统

> **一句话定位**：智源研究院在具身智能领域走了一条清晰的"**大脑优先**"路线：不做动作模型（小脑），而是专注于为机器人提供"**看懂、想清、规划**"的具身推理大模型——RoboBrain 系列（1.0 → 2.0 → 2.5），并配套跨本体的大小脑协作框架 **RoboOS**。它的定位与 DeepMind 的 Gemini Robotics-ER 高度对应：**输出可供性、轨迹、空间坐标、任务进度等"中间表征"，交给各家机器人的小脑去执行**。RoboBrain 2.5 在国产算力（摩尔线程千卡集群）上完成全流程训练，也让它成为"国产算力训练具身大模型"的标志性案例。

## 1. 故事的开端："大小脑分离"的判断

2024 年，国内具身智能讨论中最常见的一个框架是"**大脑 + 小脑**"：
- **大脑**：理解指令、理解场景、规划任务、推理空间关系——需要大模型；
- **小脑**：把规划转为精确的关节运动——需要高频、低延迟的控制模型。

智源的判断是：**中国的本体厂商有能力做小脑（运动控制、技能库），但缺少一个开源的、强大的"具身大脑"**；同时，各家机器人"各自为战"，缺少跨本体协作的操作系统。于是智源选择专注于两件事：**RoboBrain（大脑模型）+ RoboOS（协作框架）**。

## 2. 代表作一：RoboBrain 1.0 + RoboOS（2025.03）——从抽象到具体

> 论文：*RoboBrain: A Unified Brain Model for Robotic Manipulation from Abstract to Concrete*（CVPR 2025）；RoboOS 与 RoboBrain 于 2025 年 3 月 29 日在中关村论坛发布。

### 2.1 RoboBrain 1.0：三种能力

RoboBrain 1.0 把机器人操作所需的"大脑能力"拆解为从抽象到具体的三层：
1. **任务规划（Planning）**：把"把桌子收拾干净"拆成"拿起杯子 → 放进水槽 → ……"；
2. **可供性感知（Affordance）**：识别"杯子的哪个部位可以抓"（输出图像中的区域/框）；
3. **轨迹预测（Trajectory）**：预测末端执行器应该走的 2D 轨迹点序列。

为此团队构建了 **ShareRobot** 数据集——在 OXE 等开源机器人数据上标注规划、可供性与轨迹信息，用于训练 VLM 获得这些具身能力。

### 2.2 RoboOS：跨本体的"大小脑协作操作系统"

RoboOS 被宣传为**首个跨本体开源具身大小脑协作框架**：

```
            ┌──────────────────────────────┐
            │      RoboBrain（云端大脑）       │
            │  全局感知、任务分解、多机调度     │
            └──────────────────────────────┘
                    │                  ▲
         子任务分发  │                  │ 状态反馈
                    ▼                  │
  ┌──────────────────────────────────────────────┐
  │        跨机器人数据中枢（共享记忆）               │
  │   空间记忆（场景地图）· 时间记忆（任务历史）·      │
  │   本体记忆（各机器人能力与状态）                  │
  └──────────────────────────────────────────────┘
          │                │                │
          ▼                ▼                ▼
   机器人 A 小脑技能库   机器人 B 小脑技能库   机器人 C ……
  （低延迟执行：抓取、   （不同本体：人形、    
    放置、移动……）        机械臂、移动底盘）
```

- **大脑**：RoboBrain 负责理解与规划，可以同时为多台不同形态的机器人分配任务；
- **小脑技能库**：各本体厂商提供自己的低层技能（通过标准接口注册）；
- **共享记忆**：跨机器人共享空间、时间与本体信息，支持多机协作（例如一台机器人开门、另一台搬东西进去）。

### 2.3 意义

RoboOS 与 DeepMind Gemini Robotics-ER 2 的"多机分工"（2026.07）在思想上一致，但早了一年多，并且完全开源。它代表了中国"**生态协同**"式的具身路线：智源做公共大脑与协议，企业做本体与技能。

## 3. 代表作二：RoboBrain 2.0（2025.07）——空间 + 时间的统一具身大脑

> 论文：*RoboBrain 2.0 Technical Report*（BAAI RoboBrain Team，arXiv 2507.02029，至 2025.09 共五个版本）；项目页 superrobobrain.github.io

### 3.1 两种规模

| 版本 | 定位 |
|---|---|
| **RoboBrain 2.0-7B** | 轻量版，便于部署 |
| **RoboBrain 2.0-32B** | 完整版，性能最强 |

结构为"视觉编码器 + 语言模型"的标准 VLM 架构，重点在数据与训练。

### 3.2 能力体系

**空间理解**：
- **可供性预测**（哪里可以抓、哪里可以放）；
- **空间指代**（"左边第二个红色的杯子"→ 精确定位）；
- **轨迹预测**（末端执行器的运动路径）。

**时间决策**：
- **闭环交互**（根据执行反馈调整计划）；
- **多智能体长时程规划**（多台机器人协同完成长任务）；
- **场景图更新**（随着任务推进，动态更新对场景的结构化理解）。

### 3.3 训练

多阶段训练策略：通用多模态能力 → 具身空间/时间能力 → **第三阶段：具身场景下的思维链（CoT）推理**——让模型在回答空间/规划问题前先进行逐步推理。训练依托智源自研的 FlagScale 框架，评测依托 FlagEvalMM。

### 3.4 结果

- 32B 版本在**空间与时间两类基准**上均领先此前的开源与闭源模型；
- 项目页称其在 **9 个空间基准与 3 个时间基准**上达到或接近最优；
- 代码、检查点、基准全部开源。

### 3.5 意义

RoboBrain 2.0 是 2025 年中国开源"**具身推理 VLM**"的代表作，与 DeepMind Gemini Robotics-ER 1.5（同年 9 月）、NVIDIA Cosmos Reason、阿里 RynnBrain（2026.02）构成同一赛道的竞争。

## 4. 代表作三：RoboBrain 2.5（2025.12–2026.01）——从"看懂说清"到"落手做准"

> 论文：RoboBrain 2.5 技术报告（arXiv 2601.14352；alphaXiv 显示时间为 2025-12-29）；智源官方发布与摩尔线程联合公告。

### 4.1 问题：两个被低估的短板

智源在发布中指出，过去一年具身智能的"视觉理解 + 语言推理"进步明显，但从实验室走向真实部署时，常遇到"**看得见、做不对**"的问题，根源在于两个长期被低估的短板：
1. **空间维度的度量盲区**：2D 像素级的指点/框，无法告诉机器人"离我多远、多高、多深"；
2. **时间维度的过程建模不足**：模型能判断"任务成功/失败"，却无法稠密地估计"任务进行到了哪一步"。

### 4.2 两项核心升级

**（1）精确的 3D 空间推理**
- 从基于 2D 像素的定位，扩展为**带深度感知的三维坐标预测**；
- 能生成**符合物理约束的 3D 操作轨迹**（而非只是 2D 图像上的点序列）。

这意味着 RoboBrain 2.5 的输出可以**直接被机器人的运动规划器使用**，而不需要再经过复杂的 2D→3D 转换。

**（2）稠密时序价值预测**
- 能**跨视角**估计任务的执行进度与状态，输出连续的"价值/进度"信号；
- 为下游学习（例如强化学习、数据筛选、成功检测）提供**稳定的反馈信号**。

这与 PI π*0.6 的价值函数、DeepMind ER 2 的"任务进度追踪"属于同一类能力——**通用的具身价值模型/奖励模型**。在 2026 年"VLA + 真机 RL"成为热点的背景下，这一能力的价值极高。

### 4.3 国产算力训练

摩尔线程与智源基于 **FlagOS-Robo** 框架，在 **MTT S5000 千卡智算集群**上完成了 RoboBrain 2.5 的全流程训练，被宣传为**国产算力集群在具身大模型训练中的首次验证**。在高端 GPU 出口管制的背景下，这一案例对中国具身产业的算力自主具有象征意义。

### 4.4 意义

RoboBrain 2.5 的两项升级精确地命中了 2026 年具身大脑的两个关键需求：
- **3D 度量空间推理** → 让"大脑输出"可以直接驱动"小脑执行"；
- **稠密价值预测** → 让"大脑"成为 RL 自我改进的"裁判"。

智源官方将其概括为：从"**能看懂、能说清**"走向"**能落手、做得准**"。

## 5. 技术路线总结

| 版本 | 时间 | 核心能力 | 输出形式 |
|---|---|---|---|
| RoboBrain 1.0 | 2025.03 | 规划 + 可供性 + 2D 轨迹 | 文本计划、2D 区域、2D 点序列 |
| RoboBrain 2.0 | 2025.07 | 空间（可供性、指代、轨迹）+ 时间（闭环、多机、场景图）+ CoT | 同上 + 多机规划、场景图 |
| RoboBrain 2.5 | 2025.12–2026.01 | 3D 度量空间推理 + 稠密时序价值 | 3D 坐标、3D 轨迹、进度/价值信号 |

配合 RoboOS 的"大脑-共享记忆-小脑技能库"框架，智源构建了一个**以推理大脑为中心的开放具身生态**。

## 7. 未来展望与风险

**展望**：
1. **大脑 + 价值模型的双重角色**：RoboBrain 可能演进为"规划器 + 奖励模型"，支撑全行业的 RL 后训练；
2. **RoboOS 的生态化**：若足够多的本体厂商接入，可能形成中国的"机器人互操作标准"；
3. **国产算力适配**：在国产 GPU 上的训练与推理优化将持续推进。

**风险**：
1. **只有大脑、没有小脑**：在"端到端 VLA"成为主流的趋势下，纯推理大脑的价值需要通过与小脑的良好接口来体现；
2. **与大厂模型的竞争**：阿里、字节、腾讯等都在推出具身大脑模型，智源需要在开源影响力上保持领先。
