## 1. 故事的开端：为什么是"手"？

人形机器人的价值在于"**像人一样使用人类的工具与环境**"——而这几乎完全取决于**手**。夹爪能抓起大多数物体，但无法拧瓶盖、无法翻书、无法使用剪刀、无法打麻将。特斯拉把手视为"最难的硬件"（第 6 章），Figure、DeepMind（Gemini Robotics 2 五指手任务成功率 32%–92%）都把灵巧操作作为最大挑战之一。

灵初智能从一开始就把"**灵巧手的大脑**"作为主攻方向：不是先做通用 VLA 再适配灵巧手，而是**从灵巧操作的特殊性出发设计大脑**——高自由度、接触丰富、需要精细力控与在手操作。

## 2. 代表作一：DexGraspVLA（2025.02）——通用灵巧抓取的分层 VLA

> 论文：*DexGraspVLA: A Vision-Language-Action Framework Towards General Dexterous Grasping*（arXiv 2502.20900，2025.02）——灵初智能与北京大学等。

### 2.1 问题

灵巧抓取的"通用性"有两个维度：
- **物体泛化**：能抓起任意形状、材质、大小的物体；
- **环境泛化**：在不同光照、背景、杂乱程度下都能工作。

端到端训练的灵巧抓取策略往往**过拟合到训练时的视觉外观**——换个桌布颜色、换盏灯就失败。

### 2.2 方法：分层 + 领域不变表征

```
   ┌──────────────────────────────────────────┐
   │ 高层规划器：预训练 VLM                         │
   │ · 理解语言指令（"抓起最左边的水果"）            │
   │ · 在图像中定位目标（输出目标框）                 │
   └──────────────────────────────────────────┘
                     │ 目标位置
                     ▼
   ┌──────────────────────────────────────────┐
   │ 低层控制器：扩散式动作策略                      │
   │ · 输入：领域不变表征（而非原始像素）              │
   │   - 由视觉基础模型提取的特征                    │
   │   - 目标物体的分割掩码                          │
   │ · 输出：灵巧手 + 手臂的闭环动作                  │
   └──────────────────────────────────────────┘
```

**关键洞察——"领域不变表征"**：低层控制器不直接看原始图像，而是看**视觉基础模型提取的特征 + 目标掩码**。这些表征对光照、背景、纹理变化**天然不敏感**，从而让在有限数据上训练的扩散策略能泛化到全新环境。这一思想与 PointVLA（第 34 章，注入点云）、UniVLA（第 22 章，在 DINOv2 空间做潜在动作）一样，都在回答"**VLA 应该在什么表征空间里学习动作**"这个问题。

### 2.3 结果

- 在上千种**未见过的物体-光照-背景组合**上（据论文，约 1287 种）实现约 **90%** 的零样本灵巧抓取成功率；
- 对语言指令中的复杂目标描述（位置、颜色、类别）有良好理解；
- 支持杂乱场景中的连续多物体抓取。

## 3. 代表作二：Psi-R1（2025）——动作思维链 + 强化学习的长程灵巧操作

### 3.1 CoAT：动作思维链

Psi-R1 被描述为"**分层端到端 VLA + 强化学习**"模型，核心是 **CoAT（Chain of Action-Thought，动作-思维链）** 推理框架：
- 在执行长程任务时，模型**交替进行"思考"（规划下一步要做什么）与"动作"（执行精细操作）**；
- 思考链帮助模型在长任务中保持上下文、处理意外。

（"动作思维链"的思想在 2026 年被智元 GO-2、星海图 G0.5 等更广泛地采用，见第 32、39 章。）

### 3.2 训练路线：仿真强化学习 + 遥操作

灵初在 Psi-R1 阶段选择**在仿真环境中进行强化学习**（提升灵巧操作的鲁棒性与精度）并结合**遥操作数据**。

### 3.3 演示

Psi-R1 驱动的机器人展示了一系列**长程灵巧任务**：
- **打麻将**（摸牌、理牌、出牌——需要精细的在手操作与牌面识别）；
- **外卖分拣**（识别订单、抓取不同包装的外卖）；
- **商店理货**（在货架上整理商品）。

这些任务的共同点是：**长时程 + 多次精细抓放 + 需要理解场景规则**。

## 4. 代表作三：Psi-R2 + Psi-W0（2026.04.10）——人类手部数据与世界模型飞轮

### 4.1 路线转向：从"仿真 + 遥操作"到"人类数据"

2026 年 4 月 10 日，灵初发布新一代具身大模型 **Psi-R2** 与 **Psi-W0**，核心变化是：**基于人类数据预训练**。量子位以"**中国具身模型狂揽全球第一！机器人的人类数据时代来了**"为题报道——灵初成为 2026 年中国"人类数据派"（它石、智在无界、小米等）的又一重要成员。

### 4.2 开源：1000 小时人类手部操作全模态数据集

同时开源**首批 1000 小时人类手部操作全模态数据集**（宣称全球最大人类手部数据集）：
- **全模态**：第一视角视频 + 手部精细动作（手指关节级）+ 可能的触觉/力等信号；
- **聚焦"手"**：与其他人类数据集（侧重全身或整体场景）不同，它专注于手部精细操作——与灵初"灵巧手优先"的定位一致。

### 4.3 Psi-W0：动作条件世界模型

**Psi-W0** 是一个**动作条件世界模型**——给定当前观察与动作，预测未来状态。它的作用是：
- **评估策略**：在世界模型中测试 Psi-R2 的表现；
- **提升策略**：生成数据、发现失败、改进策略；
- 与 Psi-R2 形成**数据飞轮**："策略 → 世界模型评估 → 改进数据 → 更好的策略"。

### 4.4 MolmoSpaces 基准

据报道，Psi-R2 以 **46.4% 的 Oracle 成功率**登顶 **MolmoSpaces** 全球基准——这是由美国**艾伦人工智能研究所（AI2）**发起的具身基准。由海外第三方机构发起的基准登顶，比自建榜单更具说服力（但仍需注意不同基准的口径差异）。

## 7. 未来展望与风险

**展望**：
1. **人类手部数据的规模化**：从 1000 小时扩展到更大规模，可能建立"手部操作"领域的数据壁垒；
2. **世界模型飞轮**：Psi-W0 若能有效降低真机迭代成本，将加速灵巧操作的进步；
3. **场景落地**：零售理货、外卖分拣等场景是灵巧手最可能率先商业化的方向。

**风险**：
1. **灵巧手硬件的可靠性与成本**：灵巧手是最易损、最昂贵的部件，规模化部署面临挑战；
2. **人手到机器人手的迁移**：形态差异（自由度、尺寸、触觉）仍是核心难题；
3. **估值与融资不确定性**：新一轮融资尚待交割与官方确认。
