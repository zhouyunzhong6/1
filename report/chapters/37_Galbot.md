# 第 37 章 银河通用（Galbot）："仿真合成数据派"的旗手，从十亿帧抓取到"银河星脑"

> **一句话定位**：银河通用由北京大学助理教授王鹤创立，是中国具身智能领域**融资最多**的公司之一（据报道成立 34 个月完成 6 轮、累计约 70 亿元融资，其中 2026 年 3 月一轮约 25 亿元）。它最鲜明的技术标签是"**仿真合成数据**"：**GraspVLA**（2025）用**十亿帧**全仿真合成数据（SynGrasp-1B）预训练抓取基础模型并零样本迁移到真实世界；**NavFoM**（ICLR 2026）用约 800 万条跨本体导航样本训练统一导航基础模型；2026 年，它把操作、导航、全身控制整合为"**银河星脑（AstraBrain）**"——以"大脑 + 脑桥 + 小脑"架构、"**世界-动作模型（WAM）**"路线驱动轮式 G1、重载 S1 与 2026 年 8 月首发的双足人形 ET1。王鹤称公司已积累约 100 万小时人类数据与 8 万小时真实场景回流数据。

## 1. 故事的开端：一位三维视觉学者的"数据判断"

王鹤在斯坦福读博期间研究三维视觉与物体位姿估计（NOCS 等工作）。回国后在北大建立 EPIC 实验室，长期研究**灵巧抓取**：DexGraspNet（大规模灵巧抓取合成数据集）、UniDexGrasp 等。这些研究给了他一个核心信念：

> **真机数据采集太慢太贵，而物理仿真 + 程序化生成可以以几乎零边际成本产出海量高质量数据——只要能跨过 sim2real 鸿沟，合成数据就是具身智能的规模化之路。**

这一判断让银河通用成为中国"**仿真合成数据派**"的旗手，与智元（真机数据工厂）、它石（人类数据）、Generalist（人类交互数据）形成鲜明对照。

## 2. 代表作一：GraspVLA（2025）——十亿帧合成数据预训练的抓取基础模型

> 论文：*GraspVLA: a Grasping Foundation Model Pre-trained on Billion-scale Synthetic Action Data*（arXiv 2505.03233）——银河通用、北京大学等；项目页 pku-epic.github.io/GraspVLA-web；2025 年 1 月随银河通用联合北大、智源、港大发布。

### 2.1 SynGrasp-1B：十亿帧合成抓取数据

| 维度 | 内容 |
|---|---|
| 规模 | **十亿帧**级别的抓取数据（全部在仿真中生成）|
| 物体 | 从 Objaverse 中选取 **240 个类别、1 万多个**物体网格 |
| 渲染 | 照片级渲染 |
| 域随机化 | 机器人位姿、物体位姿、背景、光照、材质等全面随机化 |
| 动作 | 由运动规划等方法自动生成成功的抓取轨迹 |

### 2.2 架构：渐进式动作生成（PAG）

GraspVLA 把"抓取"拆解成一条**思维链式的渐进生成过程**：

```
   图像 + 语言指令（"抓起那个蓝色杯子"）
            │
            ▼
   VLM 主干（自回归）
     步骤 1：预测目标物体的检测框（bounding box）
             ← 互联网数据与合成数据共享这一步的监督
     步骤 2：预测抓取位姿（grasp pose）
             ← 仅合成数据有这一步的监督
            │（VLM 的 KV 缓存作为条件）
            ▼
   流匹配动作专家
     步骤 3：生成末端执行器的增量动作块（delta actions）
```

**PAG（Progressive Action Generation）的精妙之处**：
- **把互联网数据与合成数据"缝合"在一起**：检测框这一步，互联网上有海量带框标注的图像（可以教模型"认识更多物体"）；抓取位姿与动作这两步，只有合成数据有——于是模型从互联网学"**认物**"，从合成数据学"**抓物**"；
- 这让模型能够抓取**合成数据中从未出现过的长尾物体**（例如充电器、毛巾、泳镜）——因为它通过互联网数据认识了这些物体，再把抓取技能迁移过去。

据二手综述，VLM 基于 InternLM2，并融合 DINOv2 与 SigLIP 视觉特征。

### 2.3 结果

- **零样本 sim2real**：只在 SynGrasp-1B 上预训练，就能直接在真实世界中抓取；
- **开放词汇抓取**：根据自然语言指令抓取指定物体；
- **长尾泛化**：抓取合成动作数据中不存在的物体类别；
- **少样本偏好学习**：用少量示范教会模型特定的抓取偏好（例如"抓杯子把手而不是杯身"）。

### 2.4 意义与延伸

GraspVLA 是**全球首批证明"纯合成数据预训练的 VLA 可零样本迁移到真实世界"的大规模工作之一**。其思路被延伸到零售场景的 **GroceryVLA**（2025.06，宣称首个面向零售的端到端 VLA，驱动"银河太空舱"无人值守药店/便利店中的取货机器人）。

## 3. 代表作二：NavFoM（2025.09，ICLR 2026）——跨本体、跨任务的导航基础模型

> 论文：*Embodied Navigation Foundation Model*（arXiv 2509.12129，ICLR 2026）——北京大学、银河通用等；项目页 pku-epic.github.io/NavFoM-Web。前作：TrackVLA（2025.05，具身视觉跟踪 VLA）。

### 3.1 问题：导航的碎片化

具身导航长期被切分成大量子任务——视觉语言导航（VLN）、物体搜索、目标跟踪、自动驾驶——而且每种本体（四足、无人机、轮式、汽车）都有自己的模型。能否用**一个模型**处理**所有本体、所有导航任务**？

### 3.2 方法

| 设计 | 内容 |
|---|---|
| **数据** | 约 **800 万条**导航样本，覆盖**四足、无人机、轮式机器人、汽车**等本体，以及 VLN、物体搜索、目标跟踪、自动驾驶等任务（另有约 470 万条问答等数据，合计约 1270 万条，据二手综述）|
| **TVI token（时间-视角指示符）**| 用标识符 token 编码"**相机视角信息**"（不同本体的相机数量与位置不同）与"**任务的时间上下文**"——让一个模型理解"我现在是一只四足/一架无人机，有几个相机朝哪里" |
| **BATS（预算感知的 token 采样）**| 在固定的视觉 token 预算下进行采样，保证长时程导航中的计算可控 |

### 3.3 结果

- 在多种导航任务与本体上，**无需任务专门微调**即达到最优或高度有竞争力的表现；
- 例如在 HM3D-OVON（开放词汇物体导航）未见验证集上，零样本成功率从 40.8% 提升到 43.6%；
- 代码在论文接收后开源（据项目页）。

### 3.4 TrackVLA

TrackVLA（2025.05）是银河通用的具身视觉跟踪 VLA——让机器人在动态环境中持续跟随指定目标（例如跟随一个人穿过人群），是 NavFoM 的前序工作之一。

### 3.5 意义

NavFoM 体现了银河通用"**一个大脑、所有身体**"的理念在导航维度上的实现。它的 TVI token 设计（把本体信息作为输入 token）与 GR00T 的本体专属编解码器、RDT 的统一动作空间，是三种不同的"跨本体"技术方案。

## 4. 代表作三：银河星脑 AstraBrain（2026）——大脑、脑桥、小脑与世界动作模型

> 来源：2026 年央视春晚演示；2026 年 8 月世界机器人大会（Galbot ET1 首发）；王鹤 2026 年数博会主旨演讲；百度百科"银河星脑"条目及媒体报道。

### 4.1 架构：大脑 + 脑桥 + 小脑

```
   ┌────────────────────────────────────────┐
   │ 大脑：AstraBrain WAM（世界-动作模型）      │  ← 慢，理解与规划
   │ · 把动作从具体关节抽象为"抓取、推拉"等      │
   │   物理操作，以便跨本体复用                  │
   └────────────────────────────────────────┘
                     │
            ┌────────────────┐
            │      脑桥       │  ← 连接快慢系统，异步协同
            └────────────────┘
                     │
   ┌────────────────────────────────────────┐
   │ 小脑：AstraBrain-WBC（全身控制）           │  ← 快，全身运动控制
   │ · 基于大规模人类动作数据训练                │
   └────────────────────────────────────────┘
                     │
   ┌────────────────────────────────────────┐
   │ AstraBrain-Agent：理解指令与决策           │
   └────────────────────────────────────────┘
                     ↓
       双足 ET1 / 轮式 G1 / 重载 S1（一颗"星脑"，所有身体）
```

### 4.2 WAM（世界-动作模型）

银河通用称其 WAM 路线由其团队于 **2025 年 ICCV** 首次提出（公司说法）。其宣传重点是**数据利用能力**——WAM 可以统一处理：
- **虚拟与真实数据**（仿真合成 + 真机）；
- **人类与机器人混合数据**；
- **有动作标签与无动作标签的数据**（例如人类视频）。

**AstraBrain WAM 0.5** 被称为"全球首个通用大脑基座模型"（公司说法），其关键设计是**把动作从具体关节抽象为"抓取、推拉"等物理操作**——这样同一个大脑输出的"操作意图"，可以被双足、轮式、重载等不同本体的小脑各自执行。

### 4.3 AstraBrain-WBC：小脑的缩放定律

- **WBC 0.5**：据称基于"有史以来最大规模"的人类动作数据训练，并宣称**验证了运动控制领域的缩放定律**；
- **WBC 1.0**：随 2026 年 8 月发布的双足 ET1 搭载。

### 4.4 数据：100 万小时人类数据 + 8 万小时回流数据

王鹤披露，公司已积累约 **100 万小时人类数据**与 **8 万小时真实场景回流数据**（未见独立核实）。这说明银河通用的数据策略在 2026 年已从"**仿真合成为主**"扩展为"**合成 + 人类 + 真实回流**"三源融合——与 NVIDIA 的"数据金字塔"思路趋同。

### 4.5 ET1：双足首秀

2026 年 8 月 19 日世界机器人大会上，银河通用首次发布**双足人形 Galbot ET-1**，并展示了打网球等动态能力；与 G1、S1 一起，体现了"**一颗星脑，所有身体**"的跨本体主张。

## 7. 未来展望与风险

**展望**：
1. **双足 + 星脑**：ET1 的推出意味着银河通用开始进入全尺寸人形赛道，"一颗星脑驱动所有身体"将面临真正的跨形态检验；
2. **零售场景的数据飞轮**：太空舱等商业部署带来的真实回流数据（8 万小时）是其独特资产；
3. **国家级平台**：牵头的具身大模型重点实验室可能带来更多资源与合作。

**风险**：
1. **sim2real 天花板**：在需要精细力控与可形变物体处理的任务上，合成数据的局限可能凸显；
2. **宣传与验证的落差**：多项"全球首个"宣称缺乏独立验证；
3. **估值压力**：高额融资需要更快的商业化兑现。
