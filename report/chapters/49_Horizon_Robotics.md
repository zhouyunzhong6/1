# 第 49 章 地平线（Horizon Robotics）与地瓜机器人：智驾芯片巨头的"一个大脑，多种形态"——H-RDT、HoloMotion 与 HoloBrain

> **一句话定位**：地平线是中国最大的智能驾驶芯片与算法公司之一，其分拆的**地瓜机器人（D-Robotics）**是中国机器人开发者平台（RDK 系列）的主要提供者（开发者生态超过 10 万人；2026 年 4 月完成 1.5 亿美元 B2 轮）。2025–2026 年，地平线把智驾的"**端到端 + 端侧部署**"能力迁移到具身，形成了一套**开源**的大小脑组合：**H-RDT**（2025.07，AAAI 2026，用 EgoDex 人类第一视角数据预训练的 2B 双臂扩散 Transformer）、**HoloMotion**（2025.11 起，人形全身运动基础模型，以视频重建动作为多样性主来源）、**HoloBrain-0**（2026.02，显式融入"本体先验"——多视角相机参数与 URDF 运动学——的 VLA，0.2B 小版本可媲美大得多的基线）以及全栈 VLA 基础设施 **RoboOrchard**。地平线的独特优势是"**芯片 + 模型 + 开发者生态**"的端侧闭环。

## 1. 故事的开端：智驾芯片公司的"第二曲线"

地平线的核心业务是**智能驾驶的芯片与算法**（征程系列芯片），其核心能力是：**在有限的端侧算力上运行端到端感知-决策模型**。当人形机器人兴起时，余凯的判断是：**机器人与汽车一样，是"端侧 AI"的载体，而端侧 AI 的瓶颈是"算力-功耗-模型效率"三角**——这正是地平线的强项。

地平线的具身战略是"**一个大脑，多种形态**"：同一套智能内核（模型 + 芯片 + 工具链）部署到人形、机械臂、移动机器人等不同形态上；并通过地瓜机器人的 RDK 平台，把这套能力开放给海量开发者。

## 2. 代表作一：H-RDT（2025.07，AAAI 2026）——人类操作增强的双臂扩散策略

> 论文：*H-RDT: Human Manipulation Enhanced Bimanual Robotic Manipulation*（arXiv 2507.23523，AAAI 2026）——地平线等。

### 2.1 思路：用人类手部数据预训练双臂策略

H-RDT 在 RDT（第 21 章，清华 RDT-1B）的基础上，引入**人类第一视角操作数据**作为预训练来源：
- **人类数据**：来自 **EgoDex**（苹果发布的大规模第一视角灵巧操作数据集）——约 **829 小时**、**33.8 万条**片段，带有 3D 手部姿态标注；
- **两阶段**：先在人类数据上预训练（学习"手如何操作物体"的通用模式），再在机器人数据上微调（适配具体双臂本体）。

### 2.2 架构

- **20 亿参数**的扩散 Transformer；
- **流匹配**建模复杂的动作分布。

### 2.3 结果

- 相比从零训练，仿真中提升约 **13.9%**、真实世界中提升约 **40.5%**；
- 优于 π0 与 RDT 基线；
- 在真实的**叠毛巾**任务中，据二手摘要报告完整成功率约 52%（RDT 基线约 40%，从零训练约 0%）。

### 2.4 意义

H-RDT 是"**人类第一视角数据预训练 → 双臂机器人**"的又一个有说服力的学术证据（与 UCSD HAT、智在无界 Being-H、NVIDIA EgoScale 同类），并显示了**苹果 EgoDex 这类公开人类数据集**对具身研究的价值。

## 3. 代表作二：HoloMotion（2025.11 起）——人形全身运动基础模型

> 开源项目：GitHub HorizonRobotics/HoloMotion（v1.0 2025.11，v1.1 2026.01）；技术报告 *HoloMotion-1*（arXiv 2605.15336，2026.05）。

### 3.1 定位

HoloMotion 是地平线开源的**人形全身控制基础模型**——即人形的"**小脑**"：给定目标动作（来自动捕、视频或上层大脑），驱动人形全身稳定地追踪执行。

### 3.2 关键设计

- **以视频重建动作为多样性的主要来源**：不同于主要依赖动捕数据的 SONIC（NVIDIA）、Figure S0，HoloMotion 把**从视频中重建的人体动作**作为动作多样性的主要来源，再辅以精选的动捕数据与内部动作数据——视频的规模与多样性远超动捕；
- **基于 Transformer 的动作追踪架构**；
- 规模据目录信息约 **4 亿参数**，Apache-2.0 许可（此规模信息来自第三方目录，需谨慎）；
- 有媒体报道其实现了约 300 FPS 级别的高频控制（媒体标题口径）。

### 3.3 意义

HoloMotion 与 NVIDIA SONIC、CMU BFM-Zero、Amazon FAR ResMimic、宇树/智在无界 FAST 等一起，构成 2025–2026 年"**开源人形小脑**"的竞争格局。其"视频重建动作"路线与 Berkeley VideoMimic（第 18 章）思想相通——**互联网视频是人形动作的最大宝库**。

## 4. 代表作三：HoloBrain-0（2026.02）——融入本体先验的 VLA

> 技术报告：*HoloBrain-0 Technical Report*（arXiv 2602.12062，2026-02-12，32 页）——地平线；全面开源（预训练 VLA 基座、后训练检查点、RoboOrchard 基础设施）。

### 4.1 核心创新：显式引入"本体先验"

多数 VLA 让模型从数据中**隐式学习**机器人的身体结构（相机装在哪、关节如何连接）。HoloBrain-0 的主张是：**这些信息是已知的，为什么不直接告诉模型？**

HoloBrain-0 显式输入两类**本体先验（embodiment priors）**：
1. **多视角相机参数**（内参、外参）——让模型精确知道每个相机"在哪里、朝哪里看"，从而做出准确的 **3D 空间推理**；
2. **URDF 运动学描述**——机器人的关节结构与运动学链，让模型理解"这个身体能怎么动"。

**效果**：更好的 **3D 空间推理**，以及对**不同机器人类型**的支持——同一模型可以在不同本体之间迁移（"一个大脑，多种形态"的技术实现）。

### 4.2 架构：三个核心模块

```
   ┌──────────────────────────────────┐
   │ 视觉语言模型（VLM）—— 语义主干       │
   └──────────────────────────────────┘
                     │
   ┌──────────────────────────────────┐
   │ 本体感知的动作专家（embodiment-aware │
   │ action expert）                     │
   │ · 以相机参数与 URDF 为条件            │
   └──────────────────────────────────┘
                     │
   ┌──────────────────────────────────┐
   │ （第三模块，详见技术报告）              │
   └──────────────────────────────────┘
```

### 4.3 训练："预训练 + 后训练"与测试驱动的数据采集

- **预训练-后训练**范式；
- 后训练阶段提出一种**迭代的、测试驱动的数据采集方法**——针对长时程双臂任务，先测试找到失败模式，再有针对性地采集数据（类似 TRI LBM 研究中"评估决定下一轮采集"的闭环，第 15 章）。

### 4.4 结果

- 在 **RoboTwin 2.0、LIBERO、GenieSim** 等仿真基准上达到最优；
- **0.2B（2 亿参数）小版本**可媲美大得多的基线——**支持低延迟端侧部署**（这正是地平线的核心诉求）；
- 真机演示：**叠衣服、可形变纸箱折叠、"万物抓取（Grasp Anything）"**。

### 4.5 RoboOrchard：全栈 VLA 基础设施

**RoboOrchard** 被定位为**覆盖数据整理、模型训练与部署的全栈 VLA 基础设施**，与 HoloBrain 一同开源。地瓜机器人的 **RDK S600** 原生兼容 HoloMotion 与 HoloBrain。

## 7. 未来展望与风险

**展望**：
1. **国产端侧平台**：随着中国人形出货量快速增长（2026 上半年近 2 万台），RDK 系列可能成为国产人形的主流端侧计算平台之一；
2. **小模型端侧化**：HoloBrain-0 的 0.2B 版本证明了"小而强"的可能，符合端侧部署的现实约束；
3. **大小脑统一**：HoloBrain + HoloMotion 的组合有望形成完整的开源人形大脑方案。

**风险**：
1. **与 NVIDIA 的生态竞争**：在全球范围内，NVIDIA 的软硬件生态仍占绝对优势；
2. **模型前沿性**：在通用能力上，地平线模型与 π、Gemini 等前沿模型仍有差距；
3. **评测透明度**：HoloMotion 尚无公共基准成绩。
