# 第 28 章 腾讯（Robotics X + 混元）：不造机器人，做"机器人的大脑供应商"——Tairos 与 Hy-Embodied 家族

> **一句话定位**：腾讯在具身智能上的战略可以用一句话概括——"**为机器人提供动力，而不是制造机器人（至少目前如此）**"。它以 Robotics X 实验室（张正友领导）与混元大模型团队为核心，2025 年 7 月推出模块化具身智能开放平台 **Tairos（钛螺丝）**，2026 年密集发布了 **HY-Embodied-0.5**（具身基础 VLM，4 月）、**HyVLA-0.5**（端到端操作 VLA，6 月）以及 WAIC 2026 上的"**感知-认知-行动**"三件套：Hy-Embodied-VLM-1.0、**Hy-Embodied-RxBrain-1.0**（基于 5 万小时以上具身数据的"具身世界认知基座模型"，结合语言推理与视觉想象）与 Hy-Embodied-VLA-0.5。腾讯的打法是**平台化 + 开源 + 与本体厂商战略合作**（如 2026 年 1 月与宇树的合作）。

## 1. 故事的开端：Robotics X 的"长期主义"

2018 年，腾讯成立 Robotics X 实验室，由前微软研究院首席研究员、计算机视觉领域著名学者**张正友**领导（"张正友标定法"是相机标定的经典方法）。Robotics X 早期的研究以**硬件与运动控制**为主：
- **Ollie**：轮腿结合的平衡机器人，能跳跃、翻滚；
- **Max**：四足机器人；
- 灵巧手、触觉传感等。

这些原型展示了腾讯在机器人"身体"上的研究能力，但腾讯从未把它们产品化。2023 年后，随着大模型兴起，Robotics X 与混元团队合作，把重心转向"**具身大脑**"。

腾讯的战略判断是：中国已经有宇树、智元、优必选等大量优秀的本体厂商，**腾讯的比较优势在于大模型、云计算与平台运营**——因此应该做"机器人的大脑与平台"，而非与本体厂商竞争。

## 2. 代表作一：Tairos（2025.07）——模块化具身智能开放平台

> 发布：2025 年 7 月 27 日，世界人工智能大会（WAIC 2025），腾讯 Robotics X 与福田实验室联合发布。

### 2.1 平台构成

Tairos 被称为**国内首个以模块化方式提供大模型、开发工具和数据服务的具身智能软件平台**：

| 层级 | 内容 |
|---|---|
| **模型层** | 多模态感知模型、规划大模型、感知行动联合大模型 |
| **云服务层** | 仿真平台、数据平台、开发工具 |
| **接口** | 标准化接口与 SDK，供本体厂商与开发者调用 |

### 2.2 模块化的逻辑

与 PI、Figure 等"端到端单一大模型"路线不同，Tairos 选择**模块化**：
- 本体厂商可以**按需选用**：只用感知模型、只用规划模型、或使用全套；
- 不同模块可以**独立升级**；
- 降低本体厂商接入大模型的门槛。

这种设计反映了腾讯对中国具身产业现状的判断：大多数本体厂商需要的是"**可快速集成的能力组件**"，而不是一个需要从头适配的黑盒大模型。

### 2.3 意义

Tairos 让腾讯在具身领域有了一个**商业化的平台载体**，并通过 2026 年 1 月与宇树的战略合作（推动宇树机器人在文旅景区、商场、企业展厅等场景落地）获得了真实部署场景。

## 3. 代表作二：HY-Embodied-0.5 与 HyVLA-0.5（2026.04–06）——基础 VLM 与端到端 VLA

### 3.1 HY-Embodied-0.5（2026.04）

> 论文：*HY-Embodied-0.5: Embodied Foundation Models for Real-World Agents*（腾讯 Robotics X 与混元视觉团队，arXiv 2604.07430）；权重开源于 Hugging Face（tencent/HY-Embodied-0.5）。

- **定位**：面向真实世界智能体的**具身基础视觉语言模型**家族；
- **两档规模**：
  - **约 2B 激活参数**的高效版本，面向**端侧部署**；
  - **约 32B 激活参数**的版本，面向**复杂推理**；
- 作为 Tairos 的感知与推理底座，提供场景理解、空间推理、任务规划等能力。

### 3.2 HyVLA-0.5（2026.06）

据二手报道（单一来源），**HyVLA-0.5（Hy-Embodied-0.5-VLA）** 于 2026 年 6 月中旬发布，是一个**端到端操作 VLA**：
- 训练数据强调**亚毫米级精度的 UMI 式手持采集数据**；
- 结合**真机强化学习**；
- 目标是**大幅减少对重度遥操作数据的依赖**；
- 报道称在仿真与真机任务上成功率超过 90%。

**解读**："UMI 式数据 + 真机 RL"的组合，与清华 RDT2（UMI 数据）、PI π*0.6（真机 RL）、字节 GR-RL（真机 RL）一致，说明腾讯的 VLA 路线紧跟 2025–2026 年的全球前沿配方。

## 4. 代表作三：Hy-Embodied-RxBrain-1.0（2026.07）——"具身世界认知基座模型"

> 发布：WAIC 2026（2026 年 7 月中旬，报道日期 7 月 15–23 日不等）；权重：Hugging Face tencent/Hy-Embodied-RxBrain-1.0；GitHub Tencent-Hunyuan/Hy-Embodied-RxBrain-1.0。

### 4.1 "感知-认知-行动"三件套

WAIC 2026 上，腾讯把具身模型家族重新组织为三个层次：

| 层次 | 模型 | 职责 |
|---|---|---|
| **感知** | Hy-Embodied-VLM-1.0 | 场景理解 |
| **认知** | **Hy-Embodied-RxBrain-1.0** | 世界认知：推理 + 想象 + 规划 |
| **行动** | Hy-Embodied-VLA-0.5 | 动作执行 |

并同时发布了 **TairosAgent** 框架与 **Apexio** 智能体。（据社区资料，这一系列以 Apache 2.0 许可开源。）

### 4.2 RxBrain 的核心能力：语言推理 + 视觉想象

RxBrain 被定位为"**具身世界认知基座模型**"，其独特之处在于把两种"思考方式"结合在一个模型中：

1. **语言推理**：对图像与视频进行问答与推理，理解场景、物体与任务；
2. **视觉想象**：
   - **预测执行某个动作后的近未来画面**（一种轻量的世界模型能力）；
   - **把任务分解为多个步骤，并为每一步生成"目标场景图像"**——即"用语言拆解任务步骤，同时生成每一步完成后场景应该是什么样"。

```
   用户："把桌子收拾干净"
            │
            ▼
   RxBrain：
     步骤 1："把杯子放进水槽"     → [生成：杯子在水槽中的目标图像]
     步骤 2："把盘子摞起来"       → [生成：盘子摞好的目标图像]
     步骤 3："擦桌面"             → [生成：干净桌面的目标图像]
            │
            ▼
   Hy-Embodied-VLA：以"文字子任务 + 目标图像"为条件执行每一步
```

### 4.3 与 π0.7 的对比

这一设计与 PI 的 π0.7（第 2 章）有惊人的相似性：π0.7 也用一个世界模型（以 BAGEL 初始化）生成"子目标图像"，作为 VLA 的多模态提示。区别在于：
- π0.7：子目标图像生成器是一个**独立的世界模型**，与 VLA 异步运行；
- RxBrain：把**语言规划与目标图像生成**放在**同一个认知模型**中，再交给独立的 VLA 执行。

腾讯称 RxBrain 是"**混合式世界模型与规划器**"，而非纯视觉世界模型。这代表了 2026 年具身大脑设计的一个重要趋势：**用"图像化的子目标"作为大脑与小脑之间的接口**——比纯文字更精确、比潜在向量更可解释。

### 4.4 训练数据

RxBrain 基于 **5 万小时以上**高质量具身数据训练。截至发布时，RxBrain-Bench 基准与 VQA/生成任务的微调代码仍在待发布列表中。

## 7. 未来展望与风险

**展望**：
1. **"子目标图像"接口的标准化**：若 RxBrain 的"文字 + 目标图像"规划方式被验证有效，可能成为腾讯 Tairos 平台的核心差异化能力；
2. **生态合作的放大**：通过与宇树等头部本体厂商的合作，腾讯的大脑可能获得大规模部署机会；
3. **微信/小程序生态**：腾讯的社交与服务生态可能成为服务型机器人的交互入口。

**风险**：
1. **平台路线的"被替代"风险**：若本体厂商自研大脑能力足够强（如智元、宇树均已推出自有基座模型），平台型大脑的需求可能下降；
2. **评测透明度**：缺乏在公共基准上的系统性对比；
3. **组织协同**：Robotics X 与混元团队的协同效率，决定了其模型迭代速度。
