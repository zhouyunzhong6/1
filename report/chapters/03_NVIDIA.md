## 1. 故事的开端：为什么一家芯片公司要做机器人大脑？

2024 年 3 月的 GTC 大会上，黄仁勋身后站着一排人形机器人——Figure、Agility、Apptronik、傅利叶、宇树、1X……他宣布了 **Project GR00T**（Generalist Robot 00 Technology）。这个场景本身就是 NVIDIA 机器人战略的隐喻：**NVIDIA 不造机器人，但它希望所有机器人都站在它的平台上。**

NVIDIA 的逻辑是"三台计算机"理论：

1. **训练计算机**（DGX）：训练机器人基础模型；
2. **仿真计算机**（OVX + Omniverse/Isaac Sim）：生成合成数据、做仿真训练与测试；
3. **机器人计算机**（Jetson Thor）：在机器人上运行模型。

而 GR00T 基础模型、Cosmos 世界模型，本质上都是**为了让这三台计算机被用起来的"示范应用"与"生态黏合剂"**：开源一个足够好的模型，让所有本体厂商以它为起点；它所依赖的数据生成、仿真和推理，自然全部发生在 NVIDIA 的硬件与软件栈上。

但如果只把 GR00T 看作"营销"，就低估了它。GEAR 实验室在 Jim Fan 与 Yuke Zhu 的带领下，产出了 Voyager、Eureka、MimicGen、HOVER、DreamGen、SONIC、DreamZero 等一系列有影响力的研究，其中一些在学术上处于领先位置。

## 2. 代表作一：GR00T N1（2025.03）——"数据金字塔"与开源人形双系统

> 论文：*GR00T N1: An Open Foundation Model for Generalist Humanoid Robots*（NVIDIA，arXiv 2503.14734，GTC 2025 发布）

### 2.1 要解决的问题

2025 年初，人形机器人行业面临的核心问题是：**人形机器人的真机数据极度稀缺**。不同于自动驾驶（有数百万辆车产生数据）、不同于 LLM（有整个互联网），人形机器人的遥操作数据昂贵、慢、且每家本体都不同。

GR00T N1 的回答是一座"数据金字塔"，以及一个能消化金字塔每一层数据的模型。

### 2.2 数据金字塔

```
                    ▲
                   ╱ ╲        顶层：真机数据（少而精）
                  ╱真机╲       · GR00T N1 人形预训练数据集（傅利叶 GR-1 遥操作）
                 ╱ 数据 ╲      · Open X-Embodiment、AgiBot-Alpha 等
                ╱────────╲
               ╱ 合成数据  ╲    中层：合成数据（可规模化）
              ╱            ╲   · 仿真轨迹：DexMimicGen 从少量示范自动扩增
             ╱  仿真 + 神经  ╲  · "神经轨迹"：微调视频生成模型，生成新任务视频
            ╱    轨迹        ╲
           ╱──────────────────╲
          ╱ 网络数据 + 人类视频   ╲  底层：海量但无动作标签
         ╱  Ego4D、Ego-Exo4D、    ╲  · 人类第一视角视频、互联网视频
        ╱   EPIC-KITCHENS 等       ╲
       ╱────────────────────────────╲
```

金字塔的核心难题是：**底层和中层的视频数据没有"动作标签"**——人类视频里没有机器人的关节角。GR00T N1 用了两种方法给它们"补标签"：

1. **潜在动作（Latent Actions）**：借鉴 LAPA，训练一个 VQ-VAE，输入视频的当前帧与未来帧，学习一个离散的"潜在动作码"来解释两帧之间的变化。这样任何视频都能被标注为一串潜在动作，作为一种虚拟的"LAPA 本体"参与训练。
2. **逆动力学模型（IDM）伪标签**：在有动作标签的机器人数据上训练一个 IDM（给定前后帧，预测中间动作），再用它给生成的视频标注伪动作。

**合成数据的规模**：论文报告用 DexMimicGen 在约 11 小时内生成了约 78 万条仿真轨迹（相当于约 6500 小时的人类示范）；用微调后的视频生成模型生成了数百小时的"神经轨迹"视频。

### 2.3 架构：System 2 + System 1

```
  相机图像 + 语言指令                         本体状态 + 加噪动作块
        │                                         │
        ▼                                         ▼
┌───────────────────────────┐        ┌──────────────────────────────────┐
│ System 2：Eagle-2 VLM       │        │ 本体专属编码器（每种机器人一个 MLP）   │
│ （SigLIP-2 + SmolLM2 1.7B） │        └──────────────────────────────────┘
│ · 约 10Hz 运行               │                        │
│ · 取 LLM 第 12 层（中间层）   │──── 视觉语言 token ────►│
│   的表征，而非最后一层         │       （交叉注意力）     ▼
└───────────────────────────┘        ┌──────────────────────────────────┐
                                     │ System 1：DiT（扩散 Transformer）    │
                                     │ · 流匹配，4 步去噪                    │
                                     │ · 自注意力（状态+动作）+ 交叉注意力    │
                                     │ · 输出 16 步动作块                    │
                                     └──────────────────────────────────┘
                                                        │
                                                        ▼
                                     本体专属解码器 → 关节/末端动作（约 120Hz 执行）
```

关键设计细节：

- **总参数约 22 亿**（N1-2B），其中 VLM 约 13 亿；
- **取 VLM 中间层特征**：作者发现用 LLM 第 12 层而非最后一层的表征，推理更快、下游策略效果更好——因为最后几层过度特化于"生成文本"；
- **每张图仅 64 个视觉 token**（224×224 输入，经 pixel shuffle 压缩）；
- **本体专属编解码器**：用不同的 MLP 处理不同机器人的状态与动作维度，让一个 DiT 主干支持多种本体（单臂、双臂、人形、"LAPA 虚拟本体"）；
- **推理效率**：在 L40 GPU 上采样一个 16 步动作块约 64 毫秒。

### 2.4 训练

- **预训练**：在金字塔全部数据上端到端训练（VLM 语言部分冻结），第三方汇总称 GR00T-N1-2B 预训练约使用 5 万 H100 GPU 小时（未在论文原文中逐字核实）；
- **后训练**：在特定本体/任务上微调，可只用少量数据。

### 2.5 实验结果

- **仿真基准**：在 RoboCasa（厨房移动操作）、DexMimicGen 跨本体基准、GR-1 桌面操作基准上，GR00T N1 在少数据设置下均优于 Diffusion Policy 等基线；
- **真机**：在傅利叶 GR-1 人形机器人上执行抓放、关抽屉、双手交接、工业零件摆放等任务；论文显示**在仅使用约 10% 训练数据时，GR00T N1 依然大幅领先于用全量数据训练的部分基线**，体现出预训练的样本效率优势；
- **神经轨迹的贡献**：加入视频生成的"神经轨迹"数据后，仿真与真机任务成功率都有可观提升。

### 2.6 演进：N1.5 → N1.6 → N1.7

| 版本 | 时间 | 关键变化 |
|---|---|---|
| **N1.5** | 2025.05（Computex） | VLM 升级为针对"指代与定位（grounding）"微调的 Eagle 2.5 且**完全冻结**；简化适配层；引入 **FLARE**（未来潜在表征对齐）目标，能从人类第一视角视频中学习；结合 DreamGen 合成数据，语言跟随能力显著提升 |
| **N1.6** | 2025 下半年 | VLM 换为内部 **Cosmos-Reason-2B** 变体，支持原生长宽比输入；DiT 从 16 层加深到 **32 层**；VLM 顶部 4 层解冻；去掉后处理适配器；加入更多本体数据（宇树 G1 行走操作、双臂 YAM、智元 Genie-1 等） |
| **N1.7** | 2026 | VLM 换为 **Cosmos-Reason2-2B（基于 Qwen3-VL 架构）**；DiT 维持 32 层；加入 **EgoScale** 大规模人类第一视角预训练以增强开箱即用的灵巧性；**提供商用授权**；通过 Hugging Face 博客以"开放推理 VLA"定位发布，并接入 LeRobot |

**演进的逻辑**：NVIDIA 在 2025 年的一年里不断加大"推理型 VLM"（Cosmos Reason）在 GR00T 中的比重，同时加深动作 DiT——这与 PI 的 π0.6（4B VLM + 860M 动作专家）思路相近。但到了 2026 年，NVIDIA 判断这条路线有天花板，开始转向世界动作模型（见第 4 节）。

### 2.7 意义与局限

**意义**：GR00T N1 是第一个**开源的、明确面向人形机器人的**基础模型，其"数据金字塔"框架被行业广泛引用；本体专属编解码器 + 共享主干的设计，成为跨本体 VLA 的标准做法之一。大量中国人形公司（宇树的 UnifoLM-VLA-0 就基于 Qwen2.5-VL 与 GR00T 的代码体系）以 GR00T 为起点。

**局限**：开箱即用的零样本能力有限，真实部署仍需大量后训练；"VLM 中间层 + 小 DiT"的结构在语义泛化上弱于 π0.5/Gemini Robotics；对全身行走操作的支持依赖外部全身控制器。

## 3. 代表作二：Cosmos 世界基础模型平台（2025.01–）——给物理 AI 造一个"数据宇宙"

> 论文：*Cosmos World Foundation Model Platform for Physical AI*（NVIDIA，arXiv 2501.03575，CES 2025 发布）；后续：Cosmos Predict 2/2.5、Cosmos Transfer、Cosmos Reason 1/2；应用：*DreamGen: Unlocking Generalization in Robot Learning through Neural Trajectories*（2025.05）

### 3.1 要解决的问题

如果真机数据是稀缺的，那么"能否用一个足够好的物理世界模拟器，生成无限的训练数据？"传统物理仿真（Isaac Sim）精确但"假"——渲染画面与真实世界存在视觉鸿沟，且建模每一个场景、每一种可变形物体都极其耗时。视频生成模型（如 Sora）画面逼真但"不懂物理"，也不受控制。

Cosmos 的目标是打造**面向物理 AI 的"世界基础模型（World Foundation Model, WFM）"**：一个预训练好的、懂物理、可被下游开发者微调成"某个机器人/某辆车的专属世界模拟器"的视频模型。

### 3.2 平台构成

| 组件 | 内容 |
|---|---|
| **数据管线** | 从约 2000 万小时原始视频中筛选、切分、标注，得到约 1 亿个高质量片段，重点覆盖驾驶、手部操作、人体运动、物体交互、相机运动等"物理丰富"的内容 |
| **Cosmos Tokenizer** | 视频分词器，提供连续（用于扩散模型）与离散（用于自回归模型）两种，在高压缩率下保持高重建质量 |
| **扩散式 WFM** | 7B 与 14B 两种规模，文本/图像/视频条件生成未来视频 |
| **自回归式 WFM** | 4B 与 12B 两种规模，基于离散 token 逐帧预测 |
| **后训练示例** | 相机位姿条件化、机器人操作（动作条件化的未来预测）、自动驾驶多视角生成 |
| **安全护栏** | 输入输出过滤，防止生成有害内容 |

### 3.3 Cosmos 家族的分化（2025）

- **Cosmos Predict**：世界预测模型（"给定现在，预测未来"），用于策略评估、合成数据；
- **Cosmos Transfer**：多模态条件生成（类似 ControlNet），输入仿真器渲染的分割图、深度图、边缘图，输出逼真视频——把 Isaac Sim 的"假画面"变成"真画面"，大幅缩小 sim2real 视觉鸿沟；
- **Cosmos Reason**：具备物理常识与时空推理的 VLM（Reason 1 为 7B，Reason 2 有 2B 等多个规模），既可做数据标注与过滤的"评论家"，也成为 GR00T N1.6/N1.7 的 VLM 主干。

这三者形成一个闭环：**Reason 理解与评判 → Predict 想象未来 → Transfer 把仿真变真实**。

### 3.4 DreamGen：世界模型如何变成机器人数据

DreamGen 是把 Cosmos 思想落地到人形机器人的代表应用（论文使用 WAN2.1 等视频模型作为底座，方法本身与具体视频模型解耦），它的四步流程是：

```
① 微调视频世界模型：用目标机器人（如 GR-1）的少量真机遥操作视频微调视频生成模型，
   让它"学会这台机器人的外观与运动学"
        ↓
② 提示生成"梦境"：给定初始帧 + 新的语言指令（"把水倒进杯子""用锤子敲"），
   生成大量机器人执行新任务、在新环境中的合成视频
        ↓
③ 恢复伪动作：用逆动力学模型（IDM）或潜在动作模型，从合成视频中反推动作序列
        ↓
④ 用"神经轨迹"训练策略
```

**结果**：论文报告，仅凭在单一环境中采集的"抓放"类遥操作数据，GR-1 人形机器人就能借助 DreamGen 学会在 10 个新环境中执行 22 种新行为（如倒水、敲击、折叠等动词层面的新技能）。这是"用世界模型扩展机器人技能边界"的早期有力证据。NVIDIA 随后把它产品化为 **GR00T-Dreams** 蓝图。

### 3.5 意义

Cosmos 的意义不仅在于模型本身，更在于它**把"世界模型"从研究概念变成了一套可下载、可微调的开发者工具**。它让"合成数据"从"仿真器专家的手工活"变成了"提示词 + GPU 时长"的规模化生产。中国的极佳科技（GigaWorld）、蚂蚁灵波（LingBot-World）、智元（Genie Envisioner）等，都在这一方向上与 Cosmos 形成对标或竞争。

## 4. 代表作三：DreamZero（2026.02）——"世界动作模型即零样本策略"，GR00T N2 的基础

> 论文：*World Action Models are Zero-shot Policies*（NVIDIA GEAR，arXiv 2602.15922，2026.02）；项目页 dreamzero0.github.io；NVIDIA 技术博客 *Pretrained to Imagine, Fine-Tuned to Act: The Rise of World-Action Models*

### 4.1 问题的提出：VLA 的"物理泛化"天花板

DreamZero 论文的出发点是一个尖锐的观察：

> 当前最先进的 VLA 擅长**语义泛化**（认识新物体、理解新指令），但在新环境中面对**从未见过的物理动作**时泛化很差。

原因在于 VLA 的母体是 VLM——VLM 在互联网图文上学到的是"这是什么"，而不是"世界会如何运动"。动作专家只能从有限的机器人数据中学动力学。

而视频生成模型恰恰相反：它在海量视频上学到的就是"世界如何随时间演变"——物体如何下落、布料如何折叠、手如何与物体交互。**如果机器人大脑的母体不是 VLM，而是视频生成模型，会怎样？**

### 4.2 核心思想：动作只是视频的又一个"模态"

DreamZero 的方法论可以用一句话概括：**联合生成"未来视频"与"动作"，让动作成为同一个去噪过程中被生成的另一个模态，不再需要单独的动作头。**

```
             当前观察（图像）+ 语言指令
                        │
                        ▼
  ┌────────────────────────────────────────────────┐
  │   预训练视频扩散模型（Wan2.1-I2V-14B-480P 初始化）     │
  │                                                │
  │   同一个去噪过程中联合生成：                        │
  │     · 未来若干帧视频 latent（"想象接下来会发生什么"）   │
  │     · 对应的机器人动作序列（"我要怎么做才能让它发生"） │
  └────────────────────────────────────────────────┘
                        │
              输出动作块 → 机器人执行 → 新观察 → 循环
```

这种设计带来三个好处：

1. **继承视频模型的物理先验**：140 亿参数的视频模型在海量视频中学到的运动、接触、形变规律，直接为动作生成服务；
2. **视频作为稠密监督**：与 VLA 只用"动作"监督不同，WAM 在训练时还要预测未来视频，这提供了远比动作标签更稠密的学习信号；
3. **"想象"与"行动"一致**：模型生成的动作与它想象的未来是同一个过程的产物，天然自洽。

### 4.3 训练与推理

- **母体**：阿里开源的 Wan2.1 图生视频 14B 模型；
- **机器人数据**：论文主要使用智元（AgiBot）的大规模真机数据进行后训练，这也说明中国开源数据集（AgiBot World）已成为全球前沿研究的基础资源；
- **推理速度**：项目页报告每个动作块推理约 150 毫秒，可实现约 7Hz 的闭环控制。对于一个 14B 的视频扩散模型，这是相当激进的工程优化结果（当然，7Hz 仍低于 VLA 动作专家常见的 50Hz 级别，因此高频细节仍依赖底层控制器）。

### 4.4 关键结果

- **零样本泛化**：在未见过的任务与环境上，DreamZero 的表现显著优于现有 VLA（NVIDIA 在 GTC 2026 发布 GR00T N2 预览时称：基于该架构的模型在新环境中完成新任务的成功率是领先 VLA 的两倍以上——这是厂商宣称，尚无独立评测）；
- **跨本体视频迁移**：仅用 **10–20 分钟**来自人类或其他机器人的**纯视频示范**（无动作标签），就能让模型在未见任务上获得 **42% 以上**的性能提升。这意味着"看一段视频学一个技能"开始在大模型层面变得可行。

### 4.5 GR00T N2：路线转向

2026 年 3 月 GTC 主题演讲中，黄仁勋预告了 **GR00T N2**：基于 DreamZero 研究的"世界动作模型"架构，计划于 2026 年底推出。行业评论普遍认为这标志着 **GR00T 正在从"以 VLM 为主干"转向"以世界模型为主干"**。

与此同时，现有产品线继续由 N1.7（商用授权版）承接。NVIDIA 还宣布与 Hugging Face 合作把 GR00T 1.7 引入 LeRobot 生态，并规划 Cosmos 3。

### 4.6 WAM 路线的争议

- **算力成本**：14B 视频扩散模型的训练与推理成本远高于 3–5B 的 VLA，端侧部署需要 Jetson Thor 级算力乃至更高；
- **控制频率**：7Hz 的闭环频率意味着它更像一个"高层运动规划器"，仍需与 SONIC 一类高频全身控制器配合；
- **语言与推理能力**：视频模型的语言理解远弱于 VLM，复杂指令理解和多步推理如何保证？NVIDIA 的答案可能是"Cosmos Reason 做推理 + WAM 做执行"的组合，但具体形态要等 N2 正式发布。

## 5. 补充：全身控制的"小脑"——HOVER 与 SONIC

一个人形机器人大脑如果只有"上层 VLA/WAM"，是走不了路的。NVIDIA 在全身控制上的两项代表工作：

- **HOVER（2024，与 CMU 等合作）**：一个统一的神经全身控制器，支持多种控制模式（根速度、关节角、末端位姿、动捕追踪等），通过"掩码"切换模式，避免为每种模式训练一个控制器；
- **SONIC（2025.11，arXiv 2511.07820）**：*Supersizing Motion Tracking for Natural Humanoid Whole-Body Control*。核心判断是：**"运动追踪（motion tracking）"就是人形控制的可扩展基础任务**——人类动捕数据提供了逐帧的稠密监督，无需为每个技能手工设计奖励。SONIC 把网络从 120 万参数扩展到 4200 万参数，使用约 700 小时动捕（1 亿帧以上）、约 2.1 万 GPU 小时训练，得到一个包含编码器、解码器与运动学规划器的"人形行为基础模型"，开源发布（面向宇树 G1 29 自由度构型），并提供低延迟遥操作版本。

**分层结构**：GR00T（VLA/WAM）→ 输出上层目标（末端位姿、根速度、运动片段）→ SONIC/HOVER（高频全身控制器）→ 关节力矩。这与 Figure Helix 02 的 S0/S1/S2、逐际 COSA 的 System 0/1/2 在结构上一致——**"三层大脑"正在成为人形机器人的行业共识架构**。

| 阶段 | 主干 | 动作生成 | 数据哲学 | 代表 |

NVIDIA 的路线有一个一以贯之的主题：**"数据从哪里来"**。从数据金字塔，到 Cosmos 合成数据，到 DreamGen 神经轨迹，再到 DreamZero 直接以视频为母体——NVIDIA 一直在寻找绕开"真机数据稀缺"的办法。这与 PI/Generalist 的"真实数据为王"形成了鲜明的路线对立。

## 7. 横向对比与身位

| 维度 | NVIDIA GR00T/DreamZero | PI π 系列 | DeepMind Gemini Robotics |
|---|---|---|---|
| 母体 | VLM（N1 系）→ 视频世界模型（N2） | VLM（Gemma 系） | Gemini |
| 数据哲学 | 合成 + 视频 + 真机金字塔 | 真实数据多样性 | 自有车队 + 网络数据 |
| 开源 | 权重开源，N1.7 可商用 | 上一代开源 | ER 开放 API |
| 全身控制 | SONIC/HOVER 独立开源 | 弱 | 2 代纳入 |
| 商业逻辑 | 卖芯片、卖算力、卖平台 | 卖模型/API | 卖 API/平台授权 |

**身位判断**：
- **生态位**：NVIDIA 是唯一一家在"训练-仿真-推理"三个环节都占据主导的公司，GR00T 的真正竞争力在于它与 Isaac/Cosmos/Jetson 的整合，以及 NVIDIA 作为"中立供应商"对所有本体厂商的吸引力；
- **模型能力**：GR00T N1 系列在纯模型能力上略逊于 π0.5/Gemini Robotics，但 DreamZero 在"物理动作泛化"这一维度上可能实现反超——这取决于 GR00T N2 的实际表现；
- **影响力**：Cosmos + GR00T 让"世界模型 + 合成数据"成为行业热词，在中国尤为明显。

## 8. 未来展望与风险

**展望**：
1. **GR00T N2 能否兑现**：如果 WAM 架构在真实人形部署中证明了"2 倍于 VLA"的新任务泛化能力，2027 年行业可能出现从 VLA 向 WAM 的大规模迁移；
2. **Cosmos 3 与"物理 AI 数据工厂"**：合成数据的质量与可控性将决定 NVIDIA 在数据侧的话语权；
3. **Jetson Thor 及其后继**：WAM 的高算力需求恰恰利好 NVIDIA 的端侧芯片业务——这是商业上的"自洽"。

**风险**：
1. **"既当运动员又当裁判"**：NVIDIA 的模型越强，与其客户（本体厂商、大脑公司）的竞争就越直接，可能促使客户转向自研或其他平台（例如特斯拉自研 AI5 芯片、中国厂商转向国产算力）；
2. **中国市场**：出口管制使中国人形厂商在高端训练与端侧芯片上越来越多地寻求替代（地平线、华为等），NVIDIA 在中国的生态影响力存在下滑风险；
3. **视频模型路线的不确定性**：WAM 能否满足高频、精细、强接触的工业操作要求，尚未被大规模验证。
