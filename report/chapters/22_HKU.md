# 第 22 章 香港大学（OpenDriveLab 与 MMLab）：从自动驾驶到"潜在动作"，从仿真孪生到人形全身 VLA

> **一句话定位**：港大在具身智能领域有两支极具影响力的团队：李弘扬的 **OpenDriveLab**（UniAD 获 CVPR 2023 最佳论文，后转向具身）和罗平（Ping Luo）的 **MMLab@HKU**。它们的代表性贡献是：**UniVLA（RSS 2025）**——用"任务中心的潜在动作"让 VLA 从任意视频（包括人类视频）中学习，以不到 OpenVLA 1/20 的预训练算力超越它；**RoboTwin 2.0（2025）**——可规模化的双臂操作合成数据生成器与基准；**WholeBodyVLA（ICLR 2026）**——在智元 X2 人形上用潜在动作学习实现全身"移动+操作"。港大团队与智元机器人、上海人工智能实验室深度合作（共同发布 AgiBot World 数据集），是"**学术—产业—国家实验室**"三方协同的典型。

## 1. 故事的开端：自动驾驶团队为什么转向具身？

OpenDriveLab 的 UniAD 在 2023 年获得 CVPR 最佳论文——它首次把感知、预测、规划统一到一个端到端网络中，是"端到端自动驾驶"的里程碑。李弘扬团队从中得到的经验是：**端到端 + 大规模数据 + 统一表征**。

当具身智能兴起时，团队发现机器人面临与自动驾驶早期完全相同的困境：**数据稀缺、动作空间异构、无法利用海量视频**。于是他们把自动驾驶的经验迁移过来，走了两条路：
1. **造数据**：与智元合作，发布百万级真机轨迹的 AgiBot World 数据集（详见第 32 章）；
2. **用视频**：既然机器人数据稀缺，就想办法让模型从**没有动作标签的视频**中学习——这就是 UniVLA。

## 2. 代表作一：UniVLA（RSS 2025）——任务中心的潜在动作

> 论文：Qingwen Bu, Yanting Yang, Jisong Cai, Shenyuan Gao, Guanghui Ren, Maoqing Yao, Ping Luo, Hongyang Li，*Learning to Act Anywhere with Task-centric Latent Actions*（UniVLA，RSS 2025，arXiv 2505.06111）——港大、智元等合作。

### 2.1 问题：潜在动作的"噪声"

"潜在动作（latent action）"的思想（Genie、LAPA、GR00T N1 中都有使用）是：从视频的相邻帧中学习一个离散码，来"解释"两帧之间发生了什么变化——这样任何视频都可以被标注成"潜在动作序列"，用于训练机器人策略。

但原始方法有一个大问题：**视频中的变化不全是"任务相关"的**——相机抖动、背景中走过的人、光照变化都会被编码进潜在动作，污染学习信号。

### 2.2 方法：两阶段解耦的潜在动作模型

```
阶段一：学习"任务无关"的潜在动作
   · 在 DINOv2 特征空间（而非像素空间）中做逆动力学：
     给定帧 t 与帧 t+k 的 DINOv2 特征，用 VQ-VAE 学一个离散潜在码
   · 不给语言条件 → 这一阶段的码会吸收各种变化（包括无关变化）

阶段二：学习"任务中心"的潜在动作
   · 加入语言指令作为条件，再学习一组新的潜在码
   · 由于阶段一的码已经"吸收"了与任务无关的变化，
     阶段二的码被迫只编码"与任务相关的动态"（手和物体如何按指令运动）

使用：
   · 用任务中心潜在动作标注大量视频（含人类视频、不同机器人视频）
   · 训练一个基于 Prismatic-7B 的 VLA，让它预测"任务中心潜在动作"
   · 下游只需在目标机器人上训练一个很小的"动作解码器"，把潜在动作映射为真实动作
```

关键设计：
- **在 DINOv2 特征空间而非像素空间做逆动力学**：DINOv2 特征对外观变化不敏感、更关注语义与几何，减少了无关视觉噪声；
- **语言条件化的解耦**：用"先学任务无关、再学任务相关"的两阶段，把有用的动态与噪声分开；
- **潜在动作作为跨本体"通用语言"**：不同机器人、甚至人类的视频，都被映射到同一套潜在动作空间。

### 2.3 结果

- 以**不到 OpenVLA 1/20 的预训练算力（GPU 小时）和 1/10 的下游数据**，超越 OpenVLA；
- 在 LIBERO 上成功率比 OpenVLA 高约 **18.5%**；在导航任务上高约 **29.6%**；在真机测试中高约 **36.7%**；
- 仅用 Bridge-V2 数据预训练的 UniVLA，就能超过在更大的 OXE 上训练的 OpenVLA 与 LAPA。

### 2.4 意义

UniVLA 证明了"**潜在动作的质量**"是"从视频学习"路线的关键，并给出了一个简单有效的提纯方法。它为 2025–2026 年大量"用人类视频预训练 VLA"的工作（包括 WholeBodyVLA、智元 GO-1 的潜在规划器思想）提供了技术基础。

## 3. 代表作二：RoboTwin 2.0（2025）——双臂操作的可规模化合成数据与基准

> 论文：*RoboTwin 2.0: A Scalable Data Generator and Benchmark with Strong Domain Randomization for Robust Bimanual Robotic Manipulation*（arXiv 2506.18088，2025.06/08）——港大 MMLab（罗平）与上海交大（穆尧组）等；前作 RoboTwin（CVPR 2025 Highlight；早期版本获 ECCV 2024 研讨会最佳论文）。

### 3.1 问题

双臂操作数据稀缺，而现有仿真基准要么任务少、要么场景过于"干净"（无杂物、固定光照），用它们生成的数据训练出的策略在真实世界中很脆弱。

### 3.2 三大组件

1. **RoboTwin-OD 物体库**：**731 个物体实例、147 个类别**，每个物体带有语义与操作相关的标注（如可抓取部位、功能点）；
2. **MLLM 驱动的自动化任务代码生成**：用多模态大模型生成任务执行代码（"专家策略"），并用**仿真反馈闭环修正**——生成 → 在仿真中执行 → 根据失败信息修改代码 → 再执行，使代码生成成功率提升约 **10.9%**；
3. **五维强域随机化**：**杂物、光照、背景、桌面高度、语言指令**五个维度的随机化，使生成的数据覆盖大量真实世界变化。

基准覆盖 **50 个双臂任务、5 种机器人本体**。

### 3.3 结果

用 RoboTwin 2.0 合成数据 + **仅 10 条真实示范**训练的 VLA，相对于只用 10 条真实示范的基线，性能**相对提升约 367%**。代码、数据生成器、基准与预采集数据集全部开源。

### 3.4 意义

RoboTwin 2.0 是中国学术界在"**仿真合成数据 + 标准化基准**"方向上的代表作，在国内被广泛用作 VLA 评测基准（类似 LIBERO、SimplerEnv 在国际上的地位）。它与 NVIDIA 的 DexMimicGen、斯坦福的 BEHAVIOR 形成呼应，体现了"**MLLM 生成任务 + 仿真验证**"这一自动化数据生成范式。

## 4. 代表作三：WholeBodyVLA（ICLR 2026）——人形全身移动操作的统一潜在 VLA

> 论文：Haoran Jiang, Jin Chen, Qingwen Bu, Li Chen, Modi Shi, Yanjie Zhang, Delong Li, Chuanzhe Suo, Chuang Wang, Zhihui Peng, Hongyang Li，*WholeBodyVLA: Towards Unified Latent VLA for Whole-Body Loco-Manipulation Control*（arXiv 2512.11047，ICLR 2026）；代码托管于 OpenDriveLab GitHub。

### 4.1 问题

UniVLA 解决了"从视频学操作"，但人形机器人还需要**一边走一边操作**：推着购物车走、蹲下搬箱子、转身装包。全身移动操作的遥操作数据比桌面操作更加稀缺。

### 4.2 方法：潜在动作 + 分层执行

```
大量无动作标签的人类第一视角视频
           │
           ▼
   潜在动作模型（延续 UniVLA 思路）→ 离散潜在动作
           │（作为 VLA 预训练的监督信号）
           ▼
   WholeBodyVLA（预训练 + 少量人形数据微调）
           │
           ▼
   轻量解码器 ──► 上半身：关节目标（手臂、手）
             └──► 下半身：移动指令（前进、转向、下蹲）
                           │
                           ▼
           面向移动操作的 RL 运动策略 → 稳定的下肢运动
```

关键点：
- **从无动作视频中学习**：用潜在动作模型从大量人类第一视角视频中提取监督信号，解决人形全身数据稀缺；
- **统一的潜在动作空间**：上半身操作与下半身移动在同一个潜在空间中建模，由解码器分别映射；
- **专门的 RL 运动控制器**：下半身由一个面向"移动操作"优化的 RL 策略执行（能在推重物、下蹲时保持稳定），而非通用行走控制器。

### 4.3 结果

在**智元 X2 人形机器人**上完成三类任务：**装包（Bag Packing）、装箱（Box Loading）、推车（Cart Pushing）**。其中推动 **50 公斤推车**的成功率为 **22/25**。

### 4.4 意义

WholeBodyVLA 是 2025–2026 年把"**潜在动作 + 人类视频预训练**"从桌面操作推广到**人形全身移动操作**的代表性工作，并采用了与 Figure Helix 02、NVIDIA GR00T + SONIC 同构的"上层 VLA + 下层 RL 运动控制"分层结构。它也展示了港大与智元合作的紧密程度：从数据集（AgiBot World）到模型（UniVLA）再到人形部署（X2）。

## 5. 技术路线总结

| 方向 | 代表作 | 核心思想 |
|---|---|---|
| 真实数据 | AgiBot World（与智元等）| 百万级真机轨迹、标准化采集 |
| 视频数据 | UniVLA | 任务中心潜在动作，让任意视频可用 |
| 合成数据 | RoboTwin 2.0 | MLLM 生成任务 + 仿真闭环 + 强域随机化 |
| 人形全身 | WholeBodyVLA | 潜在动作 VLA + RL 移动操作控制器 |

港大团队的研究覆盖了"**真实 / 视频 / 合成**"三种数据来源，并都提供了开源实现——这在全球学术团队中都是少见的完整度。

## 7. 未来展望

1. **潜在动作 + 世界模型**：潜在动作本质上是一种"压缩的世界变化"，与世界模型的结合（在潜在动作空间中规划）是自然方向；
2. **人形全身数据的规模化**：WholeBodyVLA 只用了三类任务，扩展到更多全身任务需要更大规模的人类视频与人形数据；
3. **评测标准**：RoboTwin 系列可能演进为覆盖人形全身任务的基准。
