# 第 40 章 自变量机器人（X Square Robot）：从开源 WALL-OSS 到"世界统一模型"WALL-B

> **一句话定位**：自变量机器人是中国具身领域**最坚定的"端到端统一大模型"派**——它从一开始就不走"大脑-小脑分层"的路线，而是追求一个统一的模型。其演进路径非常清晰：2024 年底的 VLA 模型 **WALL-A** → 2025 年 9 月开源的轻量版 **WALL-OSS**（紧耦合 VLA，统一跨层级思维链）→ 2026 年 4 月的 **WALL-B**——被称为全球首个"**世界统一模型（World Unified Model, WUM）**"架构的具身基础模型，把视觉、语言、动作与物理预测放进同一个网络中从头联合训练；35 天后搭载 WALL-B 系列模型的机器人首批进入真实家庭；5 月开源 **WALL-OSS-0.5**（完整训练栈），并相继发布事件级世界动作模型 **WALL-WM** 与下一尺度自回归世界模型 **WALL-SS**。自变量是 2026 年中国"**VLA → 原生多模态统一 + 世界模型**"转型最激进的公司。

## 1. 故事的开端："统一"的执念

自变量的创始团队对"大脑-小脑分层"有一个尖锐的批评：**模块之间传递信息时会损耗**。当一个 VLM 把它的理解压缩成一句文字指令或一个潜在向量交给动作模型时，大量对动作至关重要的细节（物体的精确形状、材质、受力）就丢失了。

联合创始人兼 CTO 王昊用一个类比来解释他们的理念：**就像 Apple Silicon 的"统一内存"取代了 CPU 与 GPU 之间来回拷贝数据的传统架构，具身大脑也应该让视觉、语言、动作与物理预测在同一个网络、同一个表征空间中直接交互。**

## 2. 代表作一：WALL-OSS（2025.09）→ WALL-OSS-0.5（2026.05）

### 2.1 WALL-OSS（2025.09）：紧耦合的 VLA

> 论文：*WALL-OSS*（arXiv 2509.11766，2025-09-08）；代码 GitHub wall-x。

WALL-OSS 是 WALL-A 的轻量开源版本，其核心特点：
- **紧耦合架构**：视觉-语言-动作在**一个可微分框架内**联合训练，而非把 VLM 与动作头松散拼接；
- **统一跨层级思维链（Uni-CoT）**：在同一个模型中贯通"**高层推理 → 子目标分解 → 细粒度动作**"，让推理与动作在同一链路中进行；
- **具身 VQA 能力**：保留并强化模型对具身场景的问答与理解能力；
- 开源发布提供**流匹配（FLOW）**与**离散 token（FAST）**两类动作输出版本（据开源仓库信息）；
- 论文报告在**指令跟随**与**长时程操作**上优于基线。

### 2.2 WALL-OSS-0.5（2026.05.28）：完全开源的训练栈

> 技术报告：*Wall-OSS-0.5 Technical Report*（arXiv 2605.30877）；官网标注发布日期 2026-05-28。

| 维度 | 内容 |
|---|---|
| 规模 | 约 **40 亿参数**的 VLA，基于约 **30 亿参数**的 VLM 主干 |
| 关键训练方法 | **梯度桥接协同训练（gradient-bridged co-training）**：动作 token 的交叉熵损失**直接更新 VLM 主干**——让主干学会"对动作有用的表征" |
| 动作 tokenizer | **视觉对齐的 RVQ（Vision-Aligned RVQ）动作分词器** |
| 开源内容 | **完整栈**：权重、训练代码、训练配方、优化器 |

**与 PI"知识隔离"的观点对比**：PI 的 KI（第 2 章）主张**截断**动作专家到 VLM 的梯度以保护 VLM；WALL-OSS-0.5 则主张通过离散动作 token 的交叉熵**桥接**梯度、让 VLM 主干**主动学习动作表征**。两者并不完全矛盾——KI 截断的是"连续流匹配专家"的梯度，同时也用 FAST 离散 token 训练 VLM；WALL-OSS-0.5 用的是"视觉对齐 RVQ 离散 token"。**共同点是：让 VLM 通过离散动作 token 学习动作，而不是被连续动作头的噪声梯度破坏。**

## 3. 代表作二：WALL-B（2026.04.21）——世界统一模型（WUM）

> 发布：2026 年 4 月 21 日；官网 x2robot.com/research。

### 3.1 从 VLA 到 WUM

自变量把 WALL-B 定位为"**从 VLA 架构向原生多模态融合架构的跨越**"，并称其**并非 WALL-A 的简单迭代，而是架构与训练范式的重写**。

| 维度 | 典型 VLA | WALL-B（WUM）|
|---|---|---|
| 结构 | VLM（预训练）+ 动作头（后接）| **单一网络** |
| 模态关系 | 视觉、语言、动作模块各自独立，信息在模块间传递 | **视觉、语言、动作与物理预测在同一网络中** |
| 训练 | 以预训练 VLM 为起点，再加动作训练 | **从零开始联合训练**（据报道）|
| 物理预测 | 通常没有 | **原生包含物理预测（世界模型能力）** |

### 3.2 为什么"从零联合训练"

如果以一个现成的 VLM 为起点，模型的表征空间已经被"图文对齐"塑造，动作与物理只能"后加"。从零联合训练意味着**模型的表征从一开始就同时为"看、说、做、预测"服务**——这与 LLM 领域"原生多模态模型（如 GPT-4o、Gemini 从训练之初就混合多模态）"的思路一致。代价是：需要极大规模的多模态具身数据与算力，无法直接继承互联网 VLM 的全部知识。

### 3.3 进入家庭：35 天后

发布会上宣布，搭载 WALL-B 系列模型的新一代机器人将在 **35 天后（2026 年 5 月 25 日）首批进入真实家庭**：
- 形态：**夹爪 + 轮式底盘**（而非灵巧手或双足）——自变量明确选择"先进入家庭、再追求形态"；
- 合作：与 **58 同城**合作，家庭部署搭载的是 **WALL-AS** 模型（WALL 系列的应用版本）。

这与 1X NEO（双足 + 遥操作兜底）、Sunday Memo（轮式 + 手套数据）、Figure（双足 + Helix 2.5）形成了家庭场景的多路线竞争。

## 4. 代表作三：WALL-WM 与 WALL-SS（2026.05–08）——事件级世界动作模型与虚拟训练场

### 4.1 WALL-WM（2026.05）：在"事件关节"处切分世界

> 论文：*WALL-WM: Carving World Action Modeling at the Event Joints*（X Square Robot Team，2026.05）；媒体称其为全球首个具备"事件级预测能力"的世界模型。

**问题：逐帧预测的低效**。大多数视频世界模型逐帧预测未来——但对机器人而言，大量帧是"无事发生"的（手在移动、物体静止），真正重要的是"**事件**"：杯子被拿起、门被打开、物体掉落。

**WALL-WM 的思路**："**在事件的关节处切分**"（化用柏拉图"在自然的关节处切分自然"的说法）——世界动作模型以**事件**而非帧为单位进行预测与建模，直接预测"下一个关键事件会是什么、需要什么动作来引发它"。媒体以"**逐帧时代终结？**"为题报道。

**意义**：这是对 1XWM、DreamZero 等"逐帧/逐片段视频生成"世界模型的一种效率与语义层面的改进思路——与宇树 WLA 只预测"动态区域"、星海图 Fast-WAM 降低延迟一样，都在解决"**世界模型太慢、太冗余**"的问题。

### 4.2 WALL-SS（2026.08）：下一尺度自回归世界模型

> 发布：2026 年 8 月下旬（报道称"机器人运动会散场后，自变量给机器人建了一座虚拟训练场"）。

- **下一尺度自回归（next-scale autoregressive）**：借鉴图像生成中"由粗到细、逐尺度生成"的思路（如 VAR），以多尺度方式生成世界；
- **定位**：一座让机器人"**在虚拟世界练出真本事**"的**虚拟训练场**——用于策略的训练、评估与强化学习。

## 5. 技术路线总结

```
2024 底   WALL-A：VLA
    ↓
2025.09   WALL-OSS：紧耦合 VLA + 统一跨层级思维链（开源）
    ↓
2026.04   WALL-B：世界统一模型（视觉 + 语言 + 动作 + 物理预测，单网络、从零联合训练）
    ↓
2026.05   WALL-AS 进入家庭（与 58 同城）；WALL-OSS-0.5 完全开源（梯度桥接 + 视觉对齐 RVQ）
          WALL-WM：事件级世界动作模型
    ↓
2026.08   WALL-SS：下一尺度自回归世界模型（虚拟训练场）
```

自变量的路线是一条"**越来越统一**"的路径：从 VLA 的模块拼接，到单网络统一，再把世界模型作为统一模型的原生能力与训练场。

## 7. 未来展望与风险

**展望**：
1. **WUM 的规模化**：若"从零联合训练"的统一模型在数据规模扩大后展现出比"VLM + 动作头"更强的物理理解，将对行业架构产生深远影响；
2. **家庭数据飞轮**：真实家庭部署带来的数据，是统一模型最需要的多模态具身数据；
3. **世界模型训练场**：WALL-SS 若能有效替代部分真机训练，将显著降低迭代成本。

**风险**：
1. **从零训练的知识缺失**：不继承互联网 VLM，可能在开放词汇理解、常识推理上弱于基于 VLM 的方案；
2. **技术细节透明度**：WALL-B 的完整技术报告与独立评测有限；
3. **家庭场景的可靠性**：轮式 + 夹爪方案在家务覆盖面上有限，用户体验与安全仍需验证。
