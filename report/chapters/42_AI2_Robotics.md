# 第 42 章 智平方（AI² Robotics）：全域全身 VLA、"快在慢中"与类脑 NeuroVLA

> **一句话定位**：智平方由郭彦东（Yandong Guo）创立，以"**全域全身 VLA**"为核心叙事——其具身大模型 **AlphaBrain**（原 AI2R Brain，2025 年 4 月更名）以 **GOVLA** 为起点，强调 360° 全空间感知与 34 自由度全身协同；与北大、港中文、智源合作的 **FiS-VLA（Fast-in-Slow，NeurIPS 2025）** 提出"**把快系统嵌入慢系统**"的双系统新范式，在 8 步动作块下实现约 117.7Hz 控制；**Video2Act**（2025.11，与北大合作）把 4D 世界模型融入 VLA；2026 年 4 月开源的 **NeuroVLA** 则走出一条极具辨识度的"**类脑**"路线——以**皮层-小脑-脊髓**三层结构、**脉冲神经网络（SNN）**动作层与 R-STDP 式在线自适应，实现毫秒级反射与极低功耗。智平方估值约 200 亿元，主力产品为轮式双臂机器人 AlphaBot 2。

## 1. 故事的开端："全域全身"的执念

大多数 VLA 只控制机械臂——输出末端位姿或关节角。但一个真实的服务/工业机器人需要：**转头看、转身找、移动底盘、升降躯干、双臂协作**。智平方的出发点是：**VLA 必须是"全域"（360° 感知）与"全身"（底盘 + 躯干 + 双臂 + 头部协同）的**。

这决定了智平方的大脑设计必须处理比"桌面双臂"高得多的动作维度与空间范围。

## 2. 代表作一：GOVLA 与 FiS-VLA——全域全身 VLA 与"快在慢中"

### 2.1 GOVLA：全域全身 VLA（AlphaBrain 早期核心）

据公开介绍，GOVLA 具备：
- **360° 全空间感知**；
- **34 自由度全身协同控制**（含底盘移动轨迹与全身动作）；
- **快慢双系统**：由**空间交互基础模型、慢系统、快系统**三部分组成——慢系统负责复杂推理与任务拆解，快系统输出全身控制动作与移动轨迹；
- 智平方称其**首次将 DeepSeek 的技术融入 VLA 构建**，以增强长程复杂任务的推理能力（公司说法）。

GOVLA 在 2026 年 3 月的一份"全球具身智能 TOP10"榜单中被作为智平方领跑的依据（该榜单带有明显的企业推广色彩，见第 41 章对榜单的讨论）。

### 2.2 FiS-VLA：快在慢中（NeurIPS 2025）

> 论文：Hao Chen, Jiaming Liu, Chenyang Gu, Zhuoyang Liu, Renrui Zhang, Xiaoqi Li, Xiao He, **Yandong Guo**, Chi-Wing Fu, Shanghang Zhang, Pheng-Ann Heng，*Fast-in-Slow: A Dual-System Foundation Model Unifying Fast Manipulation within Slow Reasoning*（arXiv 2506.01953，NeurIPS 2025）——港中文、北大、智源等（郭彦东为作者之一）。

**问题**：主流双系统（Helix、GR00T、G0）中，快系统（System 1）是一个**独立的小策略网络**，接在慢系统（大 VLM）后面。这带来两个问题：
- 快系统是小模型，**无法充分利用 VLM 的预训练知识**；
- 两个系统之间通过潜在向量或文字传递信息，存在**信息损耗与对齐困难**。

**核心思想："快"不是另一个模型，而是"慢"的一部分**：

```
   ┌──────────────────────────────────────────────┐
   │ 预训练 VLM（System 2：慢推理）                     │
   │   Transformer 层 1 … 层 N-k  → 低频运行，推理与理解  │
   │   ┌────────────────────────────────────────┐ │
   │   │ 最后 k 层被"复用"为 System 1（快执行）       │ │
   │   │ · 共享参数                                 │ │
   │   │ · 以更高频率、用不同（更轻的）输入运行         │ │
   │   │ · 输出动作块                               │ │
   │   └────────────────────────────────────────┘ │
   └──────────────────────────────────────────────┘
```

- **共享参数**：把 VLM 最后若干个 Transformer 块"改造"为高效的执行模块（System 1）；
- **异构输入与异步频率**：两个系统使用不同的输入（快系统用更轻量、高频的观察），以不同频率运行；
- **双感知协同训练（dual-aware co-training）**：联合优化两个系统。

**结果**：
- 平均成功率在仿真中**超过此前最优约 8%**，真实任务中**约 11%**；
- 在动作块大小为 8 时，控制频率达到约 **117.7Hz**。

**意义**：FiS-VLA 提出了与 Helix/GR00T"外挂快系统"、PI π0"共享注意力的动作专家"都不同的第三种方案——**快系统是慢系统的"尾部"**。它对 VLA 架构设计的讨论有重要价值。

## 3. 代表作二：Video2Act（2025.11）——融合 4D 世界模型的 VLA

> 发布：2025 年 11 月，智平方与北京大学联合推出；并入 AlphaBrain。

**核心思想**：把**世界模型**（对未来场景的预测）融入 VLA——据报道是一个**融合 4D 世界模型**（三维空间 + 时间）的 VLA 架构：
- 模型不仅理解当前场景，还预测**未来的 4D 场景变化**；
- 以这种预测作为动作生成的依据——"**从视频（预测）到动作**"，即 Video2Act 名称的含义。

**结果**：据报道在第三方评测中相较硅谷同类模型性能领先超过 30%（公司/媒体口径，未见独立验证）。

**意义**：Video2Act 是智平方对 2025–2026 年"**VLA + 世界模型融合**"潮流的回应，与星动纪元 VPP、字节 GR 系列、NVIDIA DreamZero 同属一个大方向；其"4D"的强调与小鹏 VLA 2.0 的"3D → 4D 时空"升级（2026.08）思路相通。

## 4. 代表作三：NeuroVLA（2026.04 开源）——类脑三层结构与脉冲神经网络

> 发布：2026 年 4 月，智平方推出并开源 NeuroVLA，定位为 AlphaBrain 的最新版本；同月发布一站式具身智能模型开源社区 **AlphaBrain Platform**。

### 4.1 灵感：人类神经系统的三级控制

人类的运动控制并不是"大脑直接控制每块肌肉"，而是分层的：
- **大脑皮层**：理解、规划、决策（慢）；
- **小脑**：运动协调、平滑、误差修正（中）；
- **脊髓**：反射——手碰到烫的东西会在大脑"意识到"之前缩回（极快）。

### 4.2 NeuroVLA 的三层架构

| 层级 | 类比 | 职责 | 实现 |
|---|---|---|---|
| **皮层（Cortex）** | 大脑皮层 | 语义理解与任务规划 | VLM / VLA 主干 |
| **小脑（Cerebellum）** | 小脑 | 高频运动协调与动态修正 | 高频控制模块 |
| **脊髓（Spinal Cord）** | 脊髓 | 快速执行与安全反射 | **脉冲神经网络（SNN）**，异步驱动 |

### 4.3 为什么用脉冲神经网络

**脉冲神经网络（Spiking Neural Network, SNN）** 是一类更接近生物神经元的网络——神经元以离散的"脉冲"在时间上传递信息，**事件驱动、异步运行**：
- **极低延迟的反射**：据报道，碰撞后约 **20 毫秒**内即可产生反射响应；
- **极低功耗**：在神经形态处理器上，第三方项目摘要称功耗约 **0.4W**；
- **在线自适应**：智平方介绍其引入了 **R-STDP**（奖励调制的脉冲时序依赖可塑性）式训练/学习算法——一种生物启发的局部学习规则，支持**部署阶段的在线自适应**。

### 4.4 报道的效果

- 机器人运动**抖动降低超过 75%**；
- 碰撞后约 **20 毫秒**反射；
- 功耗显著降低。

（以上为公司与媒体口径，未见独立评测。）

### 4.5 意义与争议

**意义**：NeuroVLA 是全球具身大脑中**少有的类脑/神经形态路线**。它回应了一个真实的工程需求——**安全反射**：当机器人与人或物体发生意外碰撞时，等待大模型"想明白"再反应是来不及的，必须有一个极快的、不经过大模型的反射层。这与 Agility 的"始终在线的安全层"（第 10 章）、Figure S0 的 1kHz 控制在功能上相似，但实现方式完全不同。

**争议/局限**：SNN 在大规模学习任务上的成熟度仍远低于标准深度网络；"全球首个类脑 VLA"等说法为公司宣传；R-STDP 的具体实现与效果有待论文与第三方验证。

## 5. 技术路线总结

```
2025.04  AlphaBrain（GOVLA）：全域全身 VLA，快慢双系统，34 自由度
    ↓
2025.06  FiS-VLA（NeurIPS 2025）：快系统嵌入慢系统（复用 VLM 尾部层），117.7Hz
    ↓
2025.11  Video2Act：融合 4D 世界模型的 VLA
    ↓
2026.04  NeuroVLA：皮层-小脑-脊髓三层类脑结构，SNN 反射层，在线自适应
         AlphaBrain Platform：开源社区（数据、训练、模型、评测全链路）
```

智平方的特点是**架构创新密度高**：一年内提出了三种不同的大脑架构思想（快在慢中、4D 世界模型融合、类脑分层）。

## 7. 未来展望与风险

**展望**：
1. **类脑芯片 + 机器人**：若神经形态硬件成熟，NeuroVLA 的低功耗、低延迟优势可能在端侧机器人上凸显；
2. **安全反射层的标准化**：机器人进入家庭与人共处后，"脊髓式"安全反射可能成为刚需；
3. **AlphaBrain Platform 生态**：开源社区若吸引足够开发者，可形成平台效应。

**风险**：
1. **宣传口径**："全球首个""领先 30%"等说法需独立验证；
2. **SNN 路线的不确定性**：主流深度学习生态与工具链对 SNN 支持有限；
3. **多条架构路线并行**可能分散资源。
