# 第 44 章 极佳视界（GigaAI）：世界模型"造数据"，再用世界模型"练策略"

> **一句话定位**：极佳视界（GigaAI，又称极佳科技）是中国"**世界模型驱动具身智能**"路线最纯粹的创业公司之一，获华为等机构押注（2026 年 3 月前后完成 10 亿元 Pre-B 轮）。它的技术主线可以用两句话概括：**第一，用世界模型"造数据"**——GigaWorld-0（2025.11）被其称为首个验证"世界模型生成数据能有效提升真实机器人 VLA 性能"的工作；**第二，用世界模型"练策略"**——GigaBrain-0（2025.10）是用世界模型生成数据大规模训练的 VLA，GigaBrain-0.5M\*（2026.02）进一步在世界模型中做强化学习（RAMP 框架）。2026 年，它又推出 GigaWorld-1 与 GigaWorld-Policy（世界-动作模型），并以"GigaBrain + GigaWorld + Maker H01 机器人"三位一体构建"具身基模"。

## 1. 故事的开端：从自动驾驶世界模型到具身

极佳团队较早在**自动驾驶世界模型**（驾驶场景视频生成、4D 场景重建）方向积累技术。自动驾驶行业在 2023–2024 年验证了一个关键结论：**用世界模型生成的长尾场景数据，可以有效提升端到端驾驶模型的性能**。极佳的判断是：**这一结论同样适用于具身智能**——而且由于机器人真机数据比驾驶数据稀缺得多，世界模型生成数据的价值在具身领域会更大。

---

## 2. 代表作一：GigaWorld-0（2025.11）——世界模型作为具身数据引擎

### 2.1 定位

GigaWorld-0 被极佳称为"**全球首个验证'世界模型生成数据能够有效提升真实物理机器人（VLA）性能'的里程碑式工作**"（公司说法）。其开源代码在 GitHub 上获得超过 1500 星。

### 2.2 两条分支：视频世界模型 + 3D 物理世界

> 论文：*GigaWorld-0: World Models as Data Engine to Empower Embodied AI*（GigaWorld Team，arXiv 2511.19861，2025-11-25，v2 2025-11-30）；项目页 gigaworld0.github.io。

GigaWorld-0 不是一个"会画画"的视频模型，而是一个**为 VLA 训练生产数据的统一世界模型框架**，由两条分支组成：

**（1）GigaWorld-0-Video：大规模视频生成**
- 基础模型 **GigaWorld-0-Video-Dreamer**：一个**混合专家（MoE）架构的"图像+文本 → 视频"生成模型**；
- 在其上做三种后训练，得到三个"数据迁移"变体：
  - **外观迁移**：保持机器人动作与轨迹不变，改变场景外观（材质、光照、背景、物体纹理）——"一条真实轨迹变成大量视觉多样的轨迹"；
  - **视角迁移**：从一个相机视角生成其他视角的画面；
  - **动作模仿（motion mimicry）**：例如把人类操作视频转换为机器人执行的视频。

**（2）GigaWorld-0-3D：物理可执行的 3D 场景**
- 用 **3D 生成模型**生成前景物体资产；
- 用 **3D 高斯泼溅（3DGS）**重建场景；
- 用**运动规划模块**计算机械臂**可执行**的动作——保证生成数据在几何与物理上一致，而不只是"看起来像"。

**（3）GigaTrain：高效训练框架**——采用 **FP8 精度**与**稀疏注意力**降低显存与算力开销。

**关键结论**（论文报告）：用 GigaWorld-0 生成的数据训练的 VLA（GigaBrain-0），在**训练中不使用真实世界交互**的条件下，提升了真机任务成功率与泛化能力。

### 2.3 意义

GigaWorld-0 与 NVIDIA Cosmos/DreamGen、智元 GE-Sim 属于同一方向，但更聚焦于"**生成的数据是否真的能提升真机 VLA**"这一可验证的问题——这正是世界模型在具身中最务实的价值。

## 3. 代表作二：GigaBrain-0（2025.10）——世界模型数据驱动的 VLA

> 技术报告：*GigaBrain-0: A World Model-Powered Vision-Language-Action Model*（arXiv 2510.19430，2025.10）；后续开源 GigaBrain-0 与 GigaBrain-0.1。

### 3.1 核心思想与架构

GigaBrain-0 是一个以**世界模型生成数据为重要训练来源**的 VLA，以降低对昂贵真机数据的依赖，目标是在外观、物体摆放、相机视角变化下保持泛化。

| 组件 | 设计 |
|---|---|
| 主干 | **混合 Transformer（MoT）**，以 **PaliGemma2** VLM 为基础 |
| 动作生成 | **动作扩散 Transformer（DiT）**，以**流匹配**预测连续动作 |
| 视觉 | **RGB-D 输入**：扩展 SigLIP 第一层卷积以接收深度通道；训练中**随机丢弃深度**，使模型在只有 RGB 时也能工作 |
| 具身思维链 | 中间推理 token 包括：**2D 操作轨迹（10 个关键点）**、**子目标语言**、**离散动作 token** |
| 数据 | 真机数据 + 大规模 GigaWorld 生成数据（外观/视角/动作迁移、3D 物理场景）|

**为什么是 RGB-D + 具身思维链**：深度提供精确的三维几何（与蚂蚁 LingBot-Depth、智源 RoboBrain 2.5 的"3D 化"趋势一致）；2D 轨迹关键点让模型在输出动作前先"画出"手要走的路径——这是一种**空间化的思维链**，与 RoboBrain 的轨迹预测、DM0 的空间脚手架思路相通。

### 3.1.1 GigaBrain-0-Small：面向端侧

论文提供了轻量版 **GigaBrain-0-Small**，面向 **NVIDIA Jetson AGX Orin** 等边缘设备。据二手摘要，它在 Orin 上以约 **π0 参数量的 12.5%**、约 **1/5 的 FLOPs**、约 **1/9 的显存**与约 **1/10 的延迟**取得可比的成功率（以论文表格为准）。

### 3.2 结果

- 在灵巧操作、长时程任务、移动操作等真实任务上表现出更好的泛化；
- 开源的 **GigaBrain-0.1** 被极佳称为在全球较大规模的真机评测中**超越 π0.5 等模型、排名第一**（公司口径，具体榜单与时间需以官方为准）。

## 4. 代表作三：GigaBrain-0.5M\* 与 GigaWorld-1 / GigaWorld-Policy（2026）——在世界模型中强化学习

### 4.1 GigaBrain-0.5M\*（2026.02）：世界模型强化学习 VLA

> 论文：*GigaBrain-0.5M\**（2026.02），基于 GigaBrain-0.5 构建。

**RAMP 框架**：**基于世界模型条件策略的强化学习**——
- 先用世界模型预测"**在某个动作下，未来会是什么样**"；
- 以世界模型的预测作为条件，训练/改进策略；
- 在世界模型"想象"的环境中进行强化学习，减少昂贵且危险的真机试错。

**意义**：这与 PI 的 π0.7（世界模型生成子目标）、它石 AWE 3.5（模型内 RL）、星动纪元 Ctrl-World（世界模型中评估与改进）、星海图 G-Fleet（真机 RL）共同构成 2026 年"**VLA + 世界模型 + RL**"三者融合的潮流。"M\*"的命名也呼应了 PI 的 π\*0.6（"\*"表示经过 RL 优化）。

### 4.2 GigaWorld-Policy：世界-动作模型

GigaWorld-Policy 被宣传为在主流"**世界-动作模型（WA）**"的推理效率与性能上实现全面超越（公司口径）——即把世界模型直接变成策略（与 NVIDIA DreamZero 同一方向），并重点解决推理效率问题。

### 4.3 GigaWorld-1（2026.03）

2026 年 3 月底，极佳发布 **GigaWorld-1**，宣称在世界模型评测中"再获全球第一、超越谷歌、英伟达"（媒体标题口径，未见独立核实）。

## 5. 技术路线总结

```
              世界模型（GigaWorld）
          ┌─────────┼──────────┐
          ▼         ▼          ▼
     造数据      练策略        当策略
  GigaWorld-0  GigaBrain-0.5M*  GigaWorld-Policy
  （数据引擎） （RAMP 世界模型 RL）（世界-动作模型）
          │         │          │
          └─────────┼──────────┘
                    ▼
         GigaBrain（VLA 具身基模）+ Maker H01（本体）
```

极佳是少数把世界模型同时用在"**数据生成、强化学习、直接作为策略**"三个位置的公司——与 NVIDIA（Cosmos 造数据 + DreamZero 当策略）、1X（评估 + 当策略）的布局高度相似。

## 7. 未来展望与风险

**展望**：
1. **世界模型 RL 的规模化**：若 RAMP 类方法能在真实任务上稳定带来提升，将显著降低真机数据需求；
2. **与华为等产业方的协同**：可能获得算力与场景资源；
3. **世界-动作模型的效率突破**：GigaWorld-Policy 若真正解决推理效率问题，将推动世界模型从"研究"走向"部署"。

**风险**：
1. **宣传与验证**：多个"全球第一"需要第三方评测佐证；
2. **生成数据的上限**：世界模型生成数据的物理正确性（尤其是接触与形变）仍是根本挑战；
3. **竞争**：与 NVIDIA、蚂蚁、智元等资源更雄厚的世界模型玩家竞争。
