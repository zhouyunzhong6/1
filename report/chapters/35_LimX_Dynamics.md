## 1. 故事的开端：控制理论学者的"系统观"

张巍是控制理论出身的学者，在俄亥俄州立大学任教多年后回国加入南方科技大学。控制理论的核心思想是"**系统**"：一个复杂系统由多个子系统组成，每个子系统有自己的时间尺度与职责，通过反馈回路协同工作。

这种系统观深刻影响了逐际的大脑路线。当行业在 2025 年热烈讨论"端到端 VLA 是否就是机器人大脑"时，逐际的回答是：**不是。VLA 是一种技能，而大脑是一个能调度技能、理解世界、规划任务、处理异常的"操作系统"。**

---

## 2. 代表作一：System 0——强化学习全身运动基础模型

### 2.1 从点足双足到全尺寸人形

逐际的运动控制能力是在一系列"难控"的平台上锤炼出来的：

| 平台 | 年份 | 特点与挑战 |
|---|---|---|
| **P1** | 2023 | **点足**双足（脚是一个点，没有脚掌支撑面）——静态不稳定，必须持续动态平衡，是 RL 运动控制的"极限测试"。P1 曾在野外复杂地形中完成盲走测试 |
| **TRON 1** | 2024 | 多形态双足（点足/足掌/轮足可切换）——同一套控制方法适配多种足端 |
| **CL-1** | 2024 | 人形，展示了基于 RL 的**连续上下楼梯**等动态地形能力 |
| **Oli** | 2025 | 全尺寸人形，面向家务等全身操作场景 |

### 2.2 System 0 的定位

**System 0 = 全身运动基础模型**：
- 让机器人在手臂、腿部、躯干协同运动的同时**保持稳定**；
- 在逐际的规划中，它解决的是机器人"**能走、能稳、能全身协调**"的问题；
- 技术路线为"**仿真中大规模强化学习 + sim2real**"（与 Figure S0、NVIDIA SONIC、Agility 运动皮层同属一类）。

逐际未公开 System 0 的具体模型结构与训练指标。

---

## 3. 代表作二：System 1——人形 VLA / 全身动作模型（WAM）与 FluxVLA Engine

### 3.1 System 1 的组成

- **人形 VLA**：视觉-语言-动作模型，负责从感知与指令生成操作动作；
- **全身动作模型（WAM，Whole-body Action Model）技能**：面向人形全身操作的动作模型；
- **训练基础设施**：训练上述模型所需的数据与训练工具链。

（注："WAM"在不同公司语境中含义不同：在 NVIDIA/银河通用中常指"世界动作模型（World Action Model）"，在逐际的公开表述中为"全身动作模型"。）

### 3.2 FluxVLA Engine

逐际推出 **FluxVLA Engine**，定位为**企业级开源平台**，用于 VLA 的训练、部署与管理。这与 Hugging Face LeRobot、智平方 AlphaBrain Platform、上海 AI Lab InternManip 等形成竞争——体现了 2026 年中国具身公司"**以开源平台建立开发者生态**"的趋势。

### 3.3 定位：技能，而非大脑

在逐际的体系中，System 1 的 VLA/WAM 被明确定位为"**技能**"——它们是 COSA 可以调用的能力模块，而不是整个大脑。这与 Figure（Helix S1 是大脑的一部分）、PI（π 系列 VLA 本身就是大脑）在概念上有本质区别。

## 4. 代表作三：LimX COSA（2026.01）→ COSA 0.5（2026.07）——具身智能体操作系统

> 发布：LimX COSA（2026-01-12）；COSA 0.5（2026-07-15）。

### 4.1 COSA 是什么

**COSA（Cognitive OS of Agents）** 被定位为**面向物理世界的具身 Agentic OS**——目标是让机器人同时具备**认知**与**全身运控**能力。

```
   ┌──────────────────────────────────────────────────┐
   │ System 2：认知层 —— COSA 具身智能体操作系统            │
   │ · 以大语言模型与世界模型为引擎                          │
   │ · 理解任务、规划、记忆、调度技能、处理异常               │
   └──────────────────────────────────────────────────┘
                          │ 调用技能
                          ▼
   ┌──────────────────────────────────────────────────┐
   │ System 1：技能层 —— 人形 VLA / 全身动作模型（WAM）       │
   │ · 一个个可被调用的操作与全身动作技能                     │
   └──────────────────────────────────────────────────┘
                          │ 运动目标
                          ▼
   ┌──────────────────────────────────────────────────┐
   │ System 0：运控层 —— 全身运动基础模型                    │
   │ · 平衡、协调、稳定                                     │
   └──────────────────────────────────────────────────┘
```

### 4.2 "模型只是技能，系统才是大脑"

逐际的核心论点：
- 单一的 VLA 模型擅长"在某个场景下完成某类动作"，但**长时程、多任务、需要记忆与异常处理的真实家务**，需要一个更高层的"操作系统"来组织；
- 大脑 = **认知（理解与规划）+ 记忆 + 技能调度 + 异常处理 + 运控**——这是一个系统工程问题，而不仅是一个模型问题；
- 类比：手机的"大脑"不是某个 App，而是操作系统。

### 4.3 COSA 0.5 演示

2026 年 7 月 15 日，逐际发布 COSA 0.5，并用全尺寸人形 **Oli** 演示了：
- **一镜到底、无遥操作、无剪辑**的家务场景；
- 机器人**不间断地完成一整屋家务**。

这类"一镜到底 + 无遥操作"的演示，与 Figure Helix 02 的 4 分钟洗碗机任务、1X 被质疑的遥操作兜底形成对照——2026 年，"**是否遥操作、是否剪辑**"已成为评价人形演示可信度的基本标准。

### 4.4 与其他"系统派"的对比

| "OS/系统"类方案 | 公司 | 重点 |
|---|---|---|
| **LimX COSA** | 逐际 | 三层（运控 / 技能 / 认知）一体，面向人形全身家务 |
| RoboOS | 智源 | 跨本体大小脑协作，共享记忆 |
| RynnRCP | 阿里 | 机器人上下文协议（接口标准）|
| 灵渠 OS / Genie Master | 智元 | 机器人操作系统 + 具身智能体框架 |
| Tairos / TairosAgent | 腾讯 | 模块化平台 + 智能体框架 |
| BrainNet + Co-Agent | 优必选 | 工业多机协同 + 分层智能体 |

**一个明显的中国特色**：2026 年中国公司普遍在"**模型之上再建一层系统/OS/智能体框架**"——这与美国大脑公司（PI、Generalist、Skild）"一个越来越强的端到端模型"的路线形成对照。前者强调可控、可组合、可落地；后者强调规模化与涌现。

## 6. 横向对比与身位

| 维度 | 逐际 | Figure | 宇树 | 智元 |
|---|---|---|---|---|
| 运动控制 | 顶尖（点足双足起家）| 顶尖 | 顶尖 | 强 |
| 大脑哲学 | 系统派（COSA）| 端到端三层（Helix 02）| 世界模型 + VLA | VLA + 世界模型 + 智能体框架 |
| 三层架构 | S0 / S1 / S2（COSA）| S0 / S1 / S2 | — | — |
| 开源平台 | FluxVLA Engine | 无 | 多项 | 多项 |

有趣的是，逐际与 Figure 的三层结构**命名几乎一致**（System 0/1/2），但内涵不同：Figure 的 S2 是一个 VLM，逐际的 System 2 是一个**以 LLM 与世界模型为引擎的操作系统**。

**身位**：逐际在**运动控制**上处于中国乃至全球第一梯队；在大脑上以"系统派"的鲜明主张形成差异化；其 COSA 的实际能力需要更多公开评测验证。

## 7. 未来展望与风险

**展望**：
1. **IPO 与规模化**：Pre-IPO 融资与股改完成后，逐际可能在 2027 年前后上市，获得更多研发资源；
2. **COSA 生态**：若 COSA 能够开放给其他本体厂商，可能成为人形"操作系统"的候选标准之一；
3. **家务场景**：COSA 0.5 的整屋家务演示若能转化为可靠产品，将是家庭人形的重要突破。

**风险**：
1. **"系统派"vs"端到端派"之争**：如果端到端模型的规模化带来压倒性的涌现能力，复杂的分层系统可能被简化；
2. **技术透明度**：System 0/1/2 的具体技术细节与评测公开不足；
3. **资源竞争**：与资金更雄厚的大厂、头部本体公司竞争。
