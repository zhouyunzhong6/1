## 专题 1：一条 VLA 的完整数据流——以 π0 类架构为例，从像素到电机

### 1.1 输入是什么

一个典型的 2025–2026 年 VLA（π0、GR00T、GR-3、Xiaomi-Robotics-0、DM0 等结构相近）在每个控制周期接收：

| 输入 | 典型规格 | 说明 |
|---|---|---|
| 多路相机图像 | 2–4 路，每路 224×224 或原生分辨率 | 头部/外部相机 + 腕部相机 |
| 历史帧（可选）| 0–6 帧 | π0.7 每路最多 6 帧；多数 VLA 只用当前帧 |
| 语言指令 | 一句话到一段话 | "把杯子放进水槽"；π0.5 还有高层子任务 |
| 本体状态 $q_t$ | 关节角、末端位姿、夹爪开合 | 维度因本体而异（π0 零填充到 18 维）|
| 其他条件（2026 新增）| 子目标图像、元数据、控制模式 | π0.7、RxBrain |

### 1.2 Token 化

```
图像 224×224 ──► ViT（如 SigLIP，patch 14）──► 16×16 = 256 个视觉 token
                                    └──► （可选）pixel shuffle / 压缩 ──► 64 个 token（GR00T N1、SmolVLA 的做法）
语言 ──► 分词器 ──► 约 10–50 个文本 token
状态 q_t ──► 线性层 ──► 1 个状态 token（或每个关节一个）
加噪动作块 A_t^τ（H×d，例如 50×18）──► 线性层 + 时间步 τ 嵌入 ──► H 个动作 token
```

以 3 路相机、每路 256 token 计，一个周期的 token 序列长度约为 3×256 + 30 + 1 + 50 ≈ **850**——这就是为什么高分辨率多相机会显著增加延迟，也是为什么很多工作要压缩视觉 token。

### 1.3 注意力掩码：分块因果

π0 的关键工程设计之一是**分块因果注意力（blockwise causal）**：

```
            看得见 →   [图像+文本]   [状态]   [动作]
  [图像+文本]              ✓            ✗        ✗
  [状态]                   ✓            ✓        ✗
  [动作]                   ✓            ✓        ✓
```

- [图像+文本] 只看自己 → 它的 KV 可以**缓存**，流匹配的多步积分中不必重算；
- [动作] 可以看到一切 → 动作生成以完整观察为条件；
- 块内部是**双向**注意力。

### 1.4 两组权重共享一个 Transformer（"动作专家"）

图像/文本 token 走 VLM 的 FFN 与注意力投影权重（约 3B），状态/动作 token 走"动作专家"权重（约 300M），但**所有 token 在每一层一起做自注意力**。这像一个"按 token 类型路由的两专家 MoE"。好处：动作专家可以在每一层直接读取 VLM 的中间表征，而不只是最后一层的输出。

（GR00T N1 的做法不同：VLM 先单独前向，取**第 12 层**特征，再通过**交叉注意力**送入 DiT 动作模块；FiS-VLA 则把 VLM 最后几层直接改造为快系统。三者代表了"VLM 与动作专家如何连接"的三种方案。）

### 1.5 流匹配训练：一步一步

给定一个训练样本（观察 $o_t$、真实动作块 $A_t \in \mathbb{R}^{H\times d}$）：

```python
# 伪代码（概念性，非任何公司的源码）
tau = sample_beta()                      # 采样时间 τ∈(0,1)，π0 偏向高噪声端
eps = randn_like(A_t)                    # 高斯噪声
A_tau = tau * A_t + (1 - tau) * eps      # 在噪声与真实动作之间线性插值
v_pred = model(o_t, A_tau, tau)          # 网络预测速度场
v_target = A_t - eps                     # 目标速度（从噪声指向数据）
loss = mse(v_pred, v_target)
```

（不同论文对 τ 的方向约定不同——有的令 τ=0 为数据、τ=1 为噪声，此时目标速度符号相反，本质相同。）

### 1.6 流匹配推理：积分 10 步

```python
A = randn(H, d)                  # 从纯噪声开始
dt = 1.0 / 10
for k in range(10):              # 10 步欧拉积分
    tau = k * dt
    A = A + dt * model(o_t, A, tau)   # 图像/文本的 KV 已缓存，只重算动作部分
return A                         # 得到 H 步动作块
```

**为什么流匹配取代了扩散成为主流**：①训练目标简单（回归一个速度）；②推理步数少（5–10 步即可）；③与"直线路径"（rectified flow）结合时更稳定。

### 1.7 执行：动作块与重规划

```
t=0      推理得到 A[0:50]
t=0..k   执行 A[0:k]（例如 k=25，半个块）
t=k      用最新观察重新推理，得到新块 → 与旧块剩余部分衔接
```

**衔接问题**：新块与旧块在切换点不连续 → 抖动。解决方案：
- ACT 的**时间集成**（对重叠预测加权平均）；
- PI 的**实时分块（RTC）**：把"新块的前几步必须与旧块剩余动作一致"视为一个**修补（inpainting）**约束，在流匹配推理中通过引导实现；
- Xiaomi-Robotics-0 的**干净动作前缀 + Λ 形注意力掩码**：把旧块动作作为前缀输入，但只让紧邻前缀的动作 token 看得见它，后面的 token 必须看视觉——兼顾平滑与反应性。

### 1.8 一张"延迟预算表"（示意）

| 环节 | 典型耗时（量级）|
|---|---|
| 相机采集与传输 | 10–30 ms |
| 视觉编码 + VLM 前向（3B 级）| 30–80 ms（端侧 GPU）|
| 动作专家 10 步积分 | 10–40 ms |
| 网络（若云端）| 50–150 ms |
| 合计 | 端侧约 60–150 ms；云端约 150–300 ms（Gemini Robotics 1.0 报告约 250 ms 端到端）|

动作块让 50 Hz 的**有效控制频率**成为可能，即便模型本身只能 5–15 Hz 推理。

## 专题 2：动作表示的数学——从 256 个桶到频域压缩

### 2.1 均匀离散化（RT-2 / OpenVLA）

对每个动作维度 $a_i \in [l_i, u_i]$，均匀切成 $B=256$ 个桶：
$$\text{token}_i = \left\lfloor \frac{a_i - l_i}{u_i - l_i} \cdot (B-1) \right\rceil$$
一个 7 维动作 = 7 个 token；一个 50 步动作块 = 350 个 token。问题：①高频控制下相邻步几乎相同，"预测下一个 token"信息量极低；②精度受桶宽限制。

### 2.2 FAST：把动作当成"图像"压缩

对动作块 $A \in \mathbb{R}^{H\times d}$ 的每个维度 $j$（一条长度 $H$ 的时间序列）做离散余弦变换：
$$C_{k,j} = \sum_{n=0}^{H-1} A_{n,j}\cos\left[\frac{\pi}{H}\left(n+\tfrac12\right)k\right]$$
然后：
1. 缩放并取整：$\hat C = \text{round}(\gamma \cdot C)$——平滑轨迹的能量集中在低频，高频系数大多变成 0；
2. 按"低频优先、维度交错"展平：$[\hat C_{0,1},\hat C_{0,2},\dots,\hat C_{0,d},\hat C_{1,1},\dots]$；
3. 用 **BPE** 合并常见的系数组合（尤其是大量连续的 0）。

**直观类比**：均匀离散化像"逐像素存储图片"，FAST 像"JPEG 压缩"。结果是 token 数大幅减少、每个 token 信息量更大，自回归训练效率显著提升（π0-FAST 约 5 倍训练加速）。

### 2.3 VQ-VAE 与 RVQ：学出来的码本

**VQ-VAE**：编码器 $E$ 把动作块编码为向量 $z_e$，在码本 $\{e_k\}_{k=1}^K$ 中找最近的码字 $z_q = e_{k^*}$，$k^*=\arg\min_k\|z_e-e_k\|$，解码器 $D$ 重建动作。损失：
$$\mathcal L = \|A - D(z_q)\|^2 + \|\text{sg}[z_e]-e_{k^*}\|^2 + \beta\|z_e-\text{sg}[e_{k^*}]\|^2$$
（sg 为停止梯度；第二项更新码本，第三项为承诺损失）。

**RVQ（残差向量量化）**：用多级码本逐级量化残差——第 1 级量化 $z_e$，第 2 级量化 $z_e - e^{(1)}$，……用较小码本的组合表达更精细的信息。RDT2、WALL-OSS-0.5（视觉对齐 RVQ）采用此类方法。

### 2.4 扩散（DDPM / DDIM）

**前向加噪**：$A^k = \sqrt{\bar\alpha_k}A^0 + \sqrt{1-\bar\alpha_k}\,\epsilon$；
**训练**：$\mathcal L = \mathbb E\|\epsilon - \epsilon_\theta(o, A^k, k)\|^2$；
**推理**：从 $A^K\sim\mathcal N(0,I)$ 出发逐步去噪（DDPM 约 100 步，DDIM 可降到约 10 步）。
Diffusion Policy 用这一框架表达多模态动作分布：两种都正确的绕行方式不会被"平均"成错误的中间路线。

### 2.5 潜在动作

### 2.6 表示方式选择的经验法则（2026）

| 需求 | 推荐 |
|---|---|
| 与 LLM 预训练统一、训练快 | FAST / RVQ 离散 token |
| 高频、精细、多模态动作 | 流匹配连续动作专家 |

## 专题 3：双系统与三层大脑的工程实现

### 3.1 为什么必须分频

| 层 | 参数量级 | 可承受频率 | 物理需求 |
|---|---|---|---|
| S2 推理 | 3B–70B+ | 0.5–10 Hz | 理解场景、规划步骤 |
| S1 视觉运动 | 80M–1B（或与 S2 共享）| 10–200 Hz | 跟踪物体、调整手的轨迹 |
| S0 全身控制 | 1M–50M | 200–1000 Hz | 平衡、接触力、反射 |

人的神经系统也是这样：大脑皮层"想"、小脑"协调"、脊髓"反射"。

### 3.2 层间接口的三种选择

| 接口 | 代表 | 优点 | 缺点 |
|---|---|---|---|
| **自然语言** | Gemini ER→VLA、π0.5 子任务、Robix→GR-3 | 可解释、可人工干预、模块可独立替换 | 信息损失（难以描述精确空间/力）|
| **潜在向量** | Helix S2→S1、GR00T VLM→DiT | 信息丰富、可端到端训练 | 不可解释，两层必须联合训练 |
| **结构化中间表示** | RoboBrain（3D 坐标/轨迹）、RxBrain（子目标图像）、π0.7（子目标图像）| 精确且可解释 | 需要专门训练生成这些表示 |
| **运动目标** | S1→S0：末端位姿、关节目标、参考动作片段 | 物理意义明确 | S0 需要足够通用（追踪器/行为基础模型）|

### 3.3 异步运行与"时间错位"

S2 以 7–9 Hz 输出一个潜在向量，S1 以 200 Hz 运行——S1 在大部分时刻使用的是"几十到上百毫秒前"的 S2 输出。Figure 在训练 Helix 时**人为地在 S1 与 S2 的输入之间引入时间偏移**，模拟部署时的异步延迟，使 S1 学会在"略微过时的意图"下仍能正确行动。

### 3.4 KV 缓存与层复用

- π0：图像/文本前缀的 KV 在 10 步积分中复用；
- GR-3：动作 DiT 只使用 VLM **后半部分层的 KV 缓存**，DiT 层数为 VLM 的一半；
- FiS-VLA：把 VLM **最后几层**直接作为快系统，以不同频率运行；
- GR00T N1 / SmolVLA：只用 VLM **中间层**（例如第 12 层）的特征。

这些设计的共同目标：**在不牺牲语义的前提下，把每个控制周期的计算量压到最低**。

## 专题 4：潜在动作——让无标签视频变成机器人训练数据

### 4.1 问题

互联网与人类第一视角视频有数百万小时，但**没有机器人动作标签**。潜在动作模型（Latent Action Model, LAM）的思路：**动作 = 解释两帧之间变化的最小信息**。

### 4.2 基本 LAM（Genie / LAPA 式）

```
输入：帧 x_t 与 x_{t+k}
编码器（逆动力学）：z = E(x_t, x_{t+k})        # 推断"发生了什么动作"
量化：z_q = VQ(z)                              # 离散潜在动作码，码本大小通常很小（如 8–256）
解码器（前向动力学）：x̂_{t+k} = D(x_t, z_q)    # 用当前帧 + 动作码重建未来帧
损失：重建误差 + VQ 损失
```

**关键约束**：码本很小、信息瓶颈很窄 → 编码器只能编码"最关键的变化"（动作），而不能把整帧图像抄过去。

训练好后，任何视频都可以被标注为潜在动作序列 → VLA 先学"预测潜在动作"（预训练），再用少量机器人数据学"潜在动作 → 真实动作"的解码器。

### 4.3 UniVLA 的改进：任务中心

问题：视频中的变化不全是动作（相机抖动、路人、光照）。UniVLA 的做法：
1. 在 **DINOv2 特征空间**而非像素空间做重建（对外观变化不敏感）；
2. **两阶段**：先不带语言学一组码（吸收所有变化），再**加语言条件**学第二组码——第一组码已吸收"任务无关变化"，第二组码被迫只编码"与指令相关的动态"。

### 4.4 XR-1 的改进：视觉与运动共享码本（UVMC）

双分支 VQ-VAE：视觉分支编码帧间视觉动态，运动分支编码机器人真实运动，两者**共享一个码本** + 对齐损失 → 同一个码既能从视频中读出，也能对应到真实运动。

### 4.5 在各家的使用

| 机构 | 用法 |
|---|---|
| NVIDIA GR00T N1 | 把潜在动作作为一种"虚拟本体（LAPA）"参与训练 |
| 智元 GO-1 | "潜在规划器"预测潜在动作 token，动作专家再细化（成功率 66%→78%）|
| 港大 UniVLA / WholeBodyVLA | 任务中心潜在动作；扩展到人形全身 |
| 北京人形 XR-1 | 统一视觉-运动码 |

## 专题 5：世界模型——五种用法与四种实现

### 5.1 定义

机器人世界模型：$p(o_{t+1:t+k} \mid o_{\le t}, a_{t:t+k-1})$——给定过去观察与将要执行的动作，预测未来观察（或其表征）。

### 5.2 四种实现

**(a) 像素/视频生成式**：以视频扩散模型（如 Wan、Cosmos）为基础，以动作或文本为条件生成未来帧。
**(b) 视频-动作联合生成（WAM）**：在同一去噪过程中同时生成未来视频 latent 与动作（DreamZero）——
$$p_\theta(v_{t+1:t+k}, a_{t:t+k-1}\mid o_{\le t}, \ell)$$
动作不再需要单独的头。
**(c) 潜空间预测（JEPA 式）**：编码器 $E$ 把观察映射为表征 $s=E(o)$，预测器 $P$ 学习 $\hat s_{t+1} = P(s_t, a_t)$，损失在表征空间计算：$\|\hat s_{t+1} - \text{sg}[E(o_{t+1})]\|$（V-JEPA 2-AC、RoboJEPA、Being-H0.7 一类）。
**(d) 轻量结构化预测**：只预测"哪里会动"（宇树 WLA 用光流监督动态区域）、只预测"关键事件"（自变量 WALL-WM）。

### 5.3 五种用法

| 用法 | 机制 | 代表 |
|---|---|---|
| ①造数据 | 外观/视角/人→机/仿真→真实迁移，扩充训练集 | Cosmos Transfer、DreamGen、GigaWorld-0 |
| ②评估策略 | 策略在世界模型中闭环运行，统计成功率并排序 | 1X、Ctrl-World、GE-Sim |
| ③RL 训练场 | 在世界模型中做强化学习 | AWE 3.5、GigaBrain-0.5M\*、WALL-SS、特斯拉 |
| ④生成子目标 | 世界模型生成"下一步应该是什么样"的图像作为提示 | π0.7、RxBrain |
| ⑤直接作为策略 | 生成未来并从中得到动作 | DreamZero、1XWM（+IDM）、Vidar |

### 5.4 用世界模型做规划：MPC + CEM（V-JEPA 2-AC 的方法）

```python
# 交叉熵方法（CEM）在表征空间做模型预测控制（概念伪代码）
mu, sigma = zeros(T, d_a), ones(T, d_a)
s0, s_goal = E(o_now), E(o_goal)
for it in range(n_iters):
    plans = mu + sigma * randn(N, T, d_a)          # 采样 N 条动作序列
    costs = []
    for plan in plans:
        s = s0
        for a in plan:
            s = P(s, a)                              # 在表征空间"想象"
        costs.append(norm(s - s_goal))
    elite = plans[argsort(costs)[:K]]                # 选最好的 K 条
    mu, sigma = elite.mean(0), elite.std(0)          # 更新分布
execute(mu[0])                                       # 只执行第一步，然后重新规划
```

### 5.5 世界模型的三大难题

1. **物理一致性**："看起来合理但物理上错误"（1X 坦承的失败模式）；
2. **推理速度**：14B 视频模型约 7 Hz（DreamZero）；Fast-WAM 把单步从约 800 ms 降到约 190 ms；隐式模型（Being-H-Flash）可上端侧；
3. **评估的可信度**：世界模型中的成功率与真实成功率的相关性需要验证（Ctrl-World 报告排序一致）。

## 专题 6：强化学习后训练——从 PPO 到"优势条件化"

### 6.1 为什么不直接用 PPO

PPO 等在线策略梯度方法在仿真中很成功（运动控制），但对**大 VLA + 真机**极不友好：
- 需要大量在线样本，真机太慢、太贵、有风险；
- 大模型的策略梯度方差大、训练不稳定；
- 稀疏奖励（只有"成功/失败"）。

### 6.2 RECAP：把 RL 变成"条件化监督学习"

1. 训练一个**价值函数** $V(o)$（π\*0.6 中为分布式价值，预测"还有多久完成/能否成功"）；
2. 对每个数据片段估计**优势** $A(o,a) \approx r + V(o') - V(o)$（或用多步回报）；
3. 二值化：$I = \mathbb 1[A > \delta]$（这一步"比平均好"还是"比平均差"）；
4. 训练**优势条件化策略** $\pi(a\mid o, I)$——好的与坏的数据都用，但打上标签；
5. 推理时始终令 $I=1$（"请做好的那种动作"），可选地用 **CFG** 放大：
$$\tilde\pi \propto \pi(a\mid o)\left[\frac{\pi(a\mid o, I=1)}{\pi(a\mid o)}\right]^{w}$$
理论上，当 $w$ 适当时，这等价于对"高优势动作"进行策略改进——这也是"条件化 + CFG"能实现 RL 式提升的直观原因。

**数据来源**：示范 + 自主运行（含失败）+ 人类纠正，多轮迭代。

### 6.3 HIL-SERL：小策略的高效真机 RL

- **奖励**：用少量成功/失败图像训练二分类器作为奖励；
- **算法**：RLPD（示范数据与在线数据各占一半批次、高 UTD 比的 SAC 类离策略算法）；
- **人在环路**：出错时人工接管，纠正数据进入回放缓冲区；
- 结果：1–2.5 小时内多个精密任务接近 100%（第 18 章）。

### 6.4 GR-RL：离线过滤 + 在线微调

1. **离线 RL 训练一个 critic（任务进度模型）**，在成功与失败轨迹上学习；
2. 用 critic **过滤示范中的有害片段**（让进度下降的动作）；
3. **形态对称增强**（双臂镜像）；
4. **在线 RL**：在**潜空间中探索**（由学习的噪声预测器生成探索动作），而非直接给动作加噪。

### 6.5 其他方案对照

| 方法 | 关键词 |
|---|---|
| DPPO（Pelican-VL）| RL 精炼 → 诊断薄弱能力 → 针对性 SFT，循环 |
| RAMP（GigaBrain-0.5M\*）| 世界模型条件策略 + RL |
| 模型内 RL（AWE 3.5）| 在生成的可交互世界中切片训练 |
| G-Fleet（星海图）| 分布式车队：部署 → 交互 → 回流 → 训练 |
| 价值/进度模型（ER 2、RoboBrain 2.5）| 为任意任务提供通用的进度/奖励信号 |

## 专题 7：人形全身控制——一个 S0 控制器是怎么训练出来的

### 7.1 流程总览

```
人类动作数据（AMASS / LAFAN1 / 自采动捕 / 视频重建）
        │  ① 重定向（人体骨架 → 机器人骨架）
        ▼
机器人参考动作库（剔除不可行动作）
        │  ② 仿真中训练追踪策略（PPO，数千个并行环境，域随机化）
        ▼
特权教师策略（可见未来参考、地形、摩擦、质量……）
        │  ③ 蒸馏
        ▼
可部署学生策略（仅本体感知 + 稀疏目标；常用历史窗口/Transformer 推断动力学）
        │  ④ sim2real 对齐（域随机化 / 差分动作模型 / 少量真机微调）
        ▼
真机部署（200–1000 Hz）
```

### 7.2 追踪奖励（典型形式）

$$r_t = w_p e^{-\|p^{ref}_t - p_t\|^2/\sigma_p} + w_r e^{-\|\theta^{ref}_t \ominus \theta_t\|^2/\sigma_r} + w_v e^{-\|v^{ref}_t - v_t\|^2/\sigma_v} + w_{root}(\cdot) - \text{(能耗、力矩、动作平滑、自碰撞惩罚)}$$

其中 $p$ 为关键身体部位位置、$\theta$ 为关节/部位朝向、$v$ 为速度。指数形式让奖励在误差小时接近 1、误差大时迅速衰减。

### 7.3 关键技巧

| 技巧 | 作用 | 代表 |
|---|---|---|
| 动作可行性过滤 | 去掉机器人做不到的人类动作 | H2O、ExBody2 |
| 保留交互的重定向 | 避免脚滑、穿地、手离开物体 | OmniRetarget |
| 教师-学生蒸馏 | 用特权信息训练，再蒸馏到真实可观测输入 | H2O、Berkeley 人形 RL |
| 历史/Transformer 输入 | 隐式系统辨识，适应地形与负载 | RMA、Radosavovic 等、Skild |
| 差分动作模型 | 学习 sim 与 real 的动力学差异，回到仿真微调 | ASAP |
| 残差策略 | 在通用追踪器上叠加物体交互修正 | ResMimic |
| 行为基础模型 | 一个策略被动作/目标/奖励"提示" | Meta Motivo、BFM-Zero |
| 质心感知 + MoE | 激进动作下保持平衡，分离通用基元与本体动力学 | 智在无界 FAST |

### 7.4 FB 表征的一句话直觉（Motivo / BFM-Zero）

学习前向 $F(s,a,z)$ 与后向 $B(s)$，使占用度量满足 $M^{\pi_z}(s,a,s') \approx F(s,a,z)^\top B(s')$。对任意奖励 $r$，令 $z_r = \mathbb E[r(s)B(s)]$，则 $Q^{\pi_{z_r}}(s,a)\approx F(s,a,z_r)^\top z_r$——**新任务只需算一个向量 $z_r$，无需重新训练**。

### 9.2 自动标注

- **事后指令重标注（hindsight relabeling）**：让 VLM 看一段示范视频，回答"如果要让机器人做出这段动作，应该给它什么指令"——Helix 的做法；
- **任务描述标准化**：SmolVLA 用 VLM 重写社区数据中混乱的任务描述；
- **子任务切分**：π0.5 的高层子任务标注；
- **元数据标注**：π0.7 为每段数据标注速度、质量、控制模式——让模型"知道这段数据是怎么做的"。

### 9.3 质量控制的三个原则（2026 共识）

1. **多样性优先**：每个环境/物体少量示范、覆盖尽可能多的环境与物体（清华数据缩放定律）；
2. **"脏"数据有价值，但要能被区分**：恢复行为与失败数据有用（千寻、RoboMIND 失败轨迹），但需要元数据或价值模型让模型区分好坏（π0.7、RECAP）；
3. **接口对齐**：采集设备的观察与动作空间要与部署机器人一致（UMI、Sunday 手套）。

## 专题 10：评测方法论——如何判断一个机器人大脑真的更好

### 10.1 样本量与置信区间

成功率 $\hat p$ 的标准误差 $\text{SE}=\sqrt{\hat p(1-\hat p)/n}$。要让 95% 置信区间半宽不超过 $\pm 10\%$（成功率约 50% 时）：
$$1.96\sqrt{0.25/n}\le 0.1 \Rightarrow n \ge 96$$
**含义**：一个任务只做 10–20 次试验时，"成功率 60% vs 50%"在统计上**几乎没有意义**。这正是 TRI 在 LBM 研究中强调"约 1800 次真机盲测"的原因（第 15 章）。

### 10.2 好评测的五个要素

| 要素 | 说明 | 反例 |
|---|---|---|
| **盲测** | 评测者不知道运行的是哪个模型 | 开发者自己评测自己的模型 |
| **大样本** | 每个条件足够多次试验 | 每任务 10 次 |
| **整任务成功** | 只算完整完成 | 只报"部分进度" |
| **分布外** | 新环境、新物体、新指令 | 在训练场景中测试 |
| **利益隔离** | 评测者与被测方无利益关联 | RoboArena 事件 |

### 10.3 里程碑评分

对长时程任务，除二元成功率外，可按子目标（里程碑）给出部分分数（TRI LBM、BEHAVIOR q-score），用于区分"差一点成功"和"完全失败"——但对外宣传时，应以**整任务成功率**为主。

### 10.4 读榜单时的五个问题

1. 是第三方平台还是自建榜单？
2. 是仿真还是真机？真机是否标准化？
3. 每个任务试验了多少次？有没有置信区间？
4. 比较的基线是哪个版本、是否经过同等微调？
5. "第一"是在哪个子榜、哪个模型版本（例如 GO-3 Nano Preview vs GO-3 Preview）？

## 本章小结

如果把 2026 年的机器人大脑比作一辆车：
- **VLM 主干**是导航系统（知道去哪、认得路）；
- **动作专家**是方向盘与油门（把意图变成平滑的操作）；
- **全身控制器**是底盘与悬挂（保证不翻车）；
- **世界模型**是驾驶模拟器与预判能力（想象接下来会发生什么）；
- **RL 后训练**是驾驶陪练（从错误中进步）；
- **数据**是燃料，**评测**是驾照考试。

50 个公司章节，就是 50 种不同的"造车方案"。
