## 附录 C：术语表

| 术语 | 英文 | 含义 |
|---|---|---|
| VLA | Vision-Language-Action | 视觉-语言-动作模型：输入图像与语言，输出机器人动作 |
| VLM | Vision-Language Model | 视觉语言模型，VLA 的常见"母体" |
| ER | Embodied Reasoning | 具身推理：空间理解、指点、轨迹、任务进度等 |
| WAM | World Action Model | 世界动作模型：联合预测未来世界状态与动作（注意：逐际语境中 WAM 指"全身动作模型"）|
| WUM | World Unified Model | 世界统一模型（自变量 WALL-B 提出）|
| WRAM | World Reasoning Action Model | 世界推理动作模型（智元 GO-3 提出）|
| WLA | World-Language-Action | 世界-语言-动作（宇树 UnifoLM-WLA 提出）|
| 动作专家 | Action Expert | VLA 中专门生成动作的子网络 |
| 流匹配 | Flow Matching | 学习从噪声到数据的速度场的生成方法 |
| 扩散策略 | Diffusion Policy | 用扩散模型生成机器人动作 |
| 动作分块 | Action Chunking | 一次预测未来多步动作 |
| FAST | Frequency-space Action Sequence Tokenization | PI 的频域动作分词器（注意：智在无界另有同名人形控制框架）|
| RVQ | Residual Vector Quantization | 残差向量量化 |
| 潜在动作 | Latent Action | 从视频相邻帧学习的离散动作码 |
| 双系统 | Dual System | 慢推理（System 2）+ 快执行（System 1）|
| 三层大脑 | S0/S1/S2 | 全身控制 / 视觉运动 / 推理 |
| 知识隔离 | Knowledge Insulation (KI) | 截断动作专家到 VLM 的梯度以保护 VLM 知识 |
| RECAP | RL with Experience & Corrections via Advantage-conditioned Policies | PI 的优势条件化强化学习 |
| IDM | Inverse Dynamics Model | 逆动力学模型：由前后状态推断动作 |
| sim2real | Simulation to Reality | 仿真到真实迁移 |
| 运动追踪 | Motion Tracking | 让机器人追踪参考动作（人形 S0 的主流训练任务）|
| 重定向 | Retargeting | 把人体动作映射到机器人骨架 |
| UMI | Universal Manipulation Interface | 手持夹爪无本体数据采集接口 |
| 遥操作 | Teleoperation | 人远程操控机器人采集示范 |
| 上下文学习 | In-Context Learning (ICL) | 不更新权重，从提示（如示范视频）中学会新任务 |
| 组合泛化 | Compositional Generalization | 把已知技能与已知本体/场景组合出未见过的能力 |
| OXE | Open X-Embodiment | 多机构联邦机器人数据集 |
| JEPA | Joint-Embedding Predictive Architecture | 联合嵌入预测架构（LeCun），在表征空间预测 |
| SNN | Spiking Neural Network | 脉冲神经网络 |
| Worken | — | 智元提出的"有效智能工作时长"度量 |
| RaaS | Robots as a Service | 机器人即服务 |

## 附录 D：研究方法与局限声明

1. **信息截止**：2026 年 10 月 30 日。

4. **公司口径**：大量 2026 年的成绩来自公司自评或自有榜单，本报告统一标注为"公司口径/宣称"，读者应谨慎对待。
5. **评级与预测**：第 90、91 章中的评级、梯队与预测为本报告的分析判断，不构成投资建议。
6. **遗漏**：具身智能领域发展极快，2026 年 10 月下旬至撰写日之间的少量发布可能未被覆盖；50 家之外仍有大量优秀团队（如 OpenAI、Apptronik、傅利叶、Dyna、乐聚、众擎、加速进化、帕西尼、光轮智能、北大与上海交大的多个实验室等）。
