# 第一部分 行业全景：机器人大脑的十年演进、技术构件与产业格局

> 本章是整份报告的"地图"。读完本章，读者应能把 50 家公司的任何一篇代表作，放到正确的历史位置与技术坐标上。

## 一、一句话讲清楚：机器人大脑这十年发生了什么

> **2016 年，机器人靠工程师写控制器、靠数十万次试错学一个抓取动作；2023 年，RT-2 让一个视觉语言大模型直接"说出"机器人动作；2024 年，π0 把扩散/流匹配动作专家接到大模型上，机器人第一次能稳定叠衣服；2025 年，Helix、GR00T 把"慢思考 + 快执行"的双系统装进人形机器人，世界模型开始被用来造数据和做评估；2026 年，三层大脑（推理-动作-全身控制）成为共识，VLA 与世界模型开始融合，机器人第一次出现了"看一段视频就会做"的上下文学习，以及在数十户陌生家庭中零样本做家务的能力——但最好的系统在真实复杂家务上的完整成功率，仍然只有 10%–60%。**

## 二、十年演进史：七个时代

### 时代 0（2010 年代中期以前）：编程的身体

传统机器人（包括 2013–2023 年液压 Atlas 的大部分惊艳表演）依靠**模型预测控制（MPC）+ 轨迹优化 + 手工状态机**。工程师为每个动作设计目标、约束与代价函数。优点是精确、可解释、动态性能强；缺点是**每个新任务都需要专家手工设计**，无法扩展到开放世界的成千上万种日常任务。（参见第 9 章 Boston Dynamics）

### 时代 1（2015–2019）：深度强化学习与"手臂农场"

- **端到端视觉运动策略**（Levine 等，2015）首次让神经网络从像素直接输出电机指令；
- **Google 的"手臂农场"与 QT-Opt**（2018）：7 台机械臂、约 58 万次真实抓取、离线 Q 学习，抓取成功率约 96%（第 1 章）；
- **CMU 的"50K 次尝试、700 机器人小时"**（Pinto & Gupta，2016）（第 4、19 章）；
- **仿真到真实的强化学习**在足式机器人上取得突破：ETH ANYmal、Berkeley/OSU 的 Cassie（第 10、18 章）。

**教训**：RL 能学会单一技能，但**一个技能就要几十万次试错**，无法规模化到通用操作；而**运动控制（locomotion）**则在"仿真 RL + sim2real"上找到了可规模化的道路——这条路后来成为人形"小脑"的基础。

### 时代 2（2021–2022）：语言进入机器人

- **SayCan**（Google，2022）：LLM 判断"说得通吗"，价值函数判断"做得到吗"（第 1 章）；
- **Inner Monologue、Code as Policies、Socratic Models**：语言成为机器人的"思维载体"（第 5 章 Andy Zeng）；
- **RT-1**（Google，2022.12）：13 万条示范、700+ 条指令训练一个 3500 万参数的 Transformer——"**Transformer 吃下动作**"（第 1 章）。

**教训**：LLM 能做高层规划，但底层动作仍需要独立训练的策略；数据的**多样性**比数量更影响泛化。

### 时代 3（2023）：VLA 诞生与开源联邦

- **RT-2**（2023.07）："**动作就是语言**"——把动作离散化为 token，与网络数据协同微调 55B VLM，语义泛化翻倍（第 1 章）；
- **Open X-Embodiment**（2023.10）：21 家机构、22 种本体、100 万+ 轨迹——机器人领域第一个"联邦数据集"（第 1 章）；
- **ALOHA / ACT**（斯坦福，2023）：低成本双臂遥操作 + 动作分块，10 分钟数据学会精细双臂任务（第 11、17 章）；
- **Diffusion Policy**（哥大/TRI/MIT，2023）：用扩散模型表达多模态动作分布（第 15 章）；
- **GR-1**（字节，2023.12）：视频生成式预训练提升机器人操作（第 25 章）。

**这一年确立了此后三年的两条主线**：RT-2 解决了"**语义从哪来**"（继承互联网 VLM），ACT 与 Diffusion Policy 解决了"**动作怎么生成**"（动作分块 + 生成式动作模型）。

### 时代 4（2024）：开源 VLA 与"大模型 + 动作专家"

- **Octo**（Berkeley 等，2024.05）：开源通才策略，模块化、扩散头（第 18 章）；
- **OpenVLA**（斯坦福等，2024.06）：开源 7B VLA，超越 55B 的 RT-2-X（第 17 章）；
- **UMI**（2024）：无本体手持采集，硬件无关（第 11 章）；
- **RDT-1B**（清华，2024.10）：12 亿参数双臂扩散基础模型，物理可解释统一动作空间（第 21 章）；
- **π0**（PI，2024.10）：**VLM + 流匹配动作专家**，50Hz 动作块，叠衣服——确立了此后两年主流 VLA 的标准架构（第 2 章）；
- **GR-2**（字节，2024.10）：3800 万视频片段的网络规模视频-语言-动作模型（第 25 章）；
- **人形 RL 与动作追踪**：Berkeley 的 Transformer 人形运动（第 18 章）、CMU 的 H2O/OmniH2O（第 19 章）、UCSD 的 ExBody/Open-TeleVision（第 20 章）、斯坦福 HumanPlus（第 17 章）。

### 时代 5（2025）：双系统人形、世界模型兴起、RL 进入 VLA

- **Helix**（Figure，2025.02）：S2（7B VLM，7–9Hz）+ S1（80M，200Hz），首个控制人形全上半身的 VLA（第 7 章）；
- **GR00T N1**（NVIDIA，2025.03）：开源人形双系统 + 数据金字塔（第 3 章）；
- **Gemini Robotics / ER**（DeepMind，2025.03）→ **1.5**（2025.09，思考型 VLA + Motion Transfer）（第 1 章）；
- **π0.5**（2025.04）：异构数据协同训练，走进陌生家庭（第 2 章）；
- **GO-1 / AgiBot World**（智元，2025.03）、**GraspVLA**（银河，2025.01）、**G0**（星海图，2025.08）等中国 VLA 集中涌现（第 32、37、39 章）；
- **Cosmos**（NVIDIA，2025.01）、**V-JEPA 2**（Meta，2025.06）、**Genie Envisioner**（智元，2025.08）、**WorldVLA**（阿里，2025.06）：世界模型进入机器人（第 3、12、32、26 章）；
- **全身控制基础模型**：Atlas LBM（BD+TRI，2025.08）、Agility 全身控制模型、SONIC（NVIDIA，2025.11）（第 9、10、3 章）；
- **RL 进入大 VLA**：π\*0.6 / RECAP（2025.11）、GR-RL（字节，2025.12）（第 2、25 章）；
- **缩放定律**：GEN-0（27 万小时，2025.11）、清华数据缩放定律（ICLR 2025）（第 5、41 章）。

### 时代 6（2026）：三层大脑共识、VLA × 世界模型融合、上下文学习、部署态

- **全身自主**：Helix 02（S0/S1/S2，2026.01）、Gemini Robotics 2（全身 + 五指手，2026.07）（第 7、1 章）；
- **世界动作模型**：DreamZero → GR00T N2（NVIDIA，2026.02/03）、1XWM（2026.01）、GO-3 Preview / WRAM（智元，2026.10）、UnifoLM-WLA-1.0（宇树，2026.09）、WALL-B（自变量，2026.04）、Being-H0.7（智在无界，2026.04）、RoboJEPA（Meta，2026.10）（第 3、8、32、31、40、47、12 章）；

- **上下文学习**：Skild S1（视频提示，10 分钟任务）、GEN-1.5（3–12 秒示范，一次学会）（第 4、5 章）；

## 三、技术构件拆解：一个 2026 年的机器人大脑由什么组成

### 3.1 总体架构：三层大脑

```
┌───────────────────────────────────────────────────────────────┐
│ System 2：推理与编排（大脑）                                        │
│ · 具身推理 VLM / ER 模型：空间理解、指点、轨迹、任务进度、工具调用      │
│ · 智能体 OS：记忆、技能调度、多机协同、异常处理                        │
│ · 代表：Gemini Robotics-ER、RoboBrain、RynnBrain、Robix、COSA、RxBrain │
├───────────────────────────────────────────────────────────────┤
│ System 1：视觉运动策略（操作小脑）                                    │
│ · VLA：VLM 主干 + 动作专家（扩散/流匹配/自回归）                       │
│ · 世界动作模型（WAM）：视频/潜空间世界模型 + 动作联合生成               │
│ · 代表：π 系列、GR00T、Helix S1、GO 系列、G0.5、DreamZero、1XWM       │
├───────────────────────────────────────────────────────────────┤
│ System 0：全身控制（运动小脑 / 脊髓）                                 │
│ · 运动追踪基础模型、RL 全身控制器、安全反射层                          │
│ · 代表：Helix S0、SONIC、HOVER、BFM-Zero、HoloMotion、Agility WBC      │
└───────────────────────────────────────────────────────────────┘
```

**为什么是三层**（详见第 7 章 4 节分析）：
1. **频率的物理约束**：语义推理需要数十亿参数，只能低频；全身平衡需要 1kHz 级反应，只能用小网络；
2. **数据来源不同**：S0 可以在仿真中大规模 RL；S1/S2 需要真实视觉与语义数据；
3. **可解释与可控**：分层让每层可以独立评测、升级与安全认证。

**也存在反对三层的声音**：Generalist 的"和声推理"主张取消系统 1/2 的划分（第 5 章）；自变量 WALL-B 主张单网络统一（第 40 章）；小鹏 VLA 2.0 去掉语言转译（第 30 章）。

### 3.2 VLM 主干：大脑的"语义来源"

| 主干家族 | 代表用户 | 特点 |
|---|---|---|
| Gemini（闭源）| DeepMind | 最强综合能力，云端 + 蒸馏 |
| PaliGemma / Gemma 3 | PI（π0 → π0.6/0.7）、XR-1（二手）| 小而精，开源 |
| Qwen2.5-VL / Qwen3-VL | 小米、宇树、字节 GR-3/GR-RL、阿里 RynnBrain、NVIDIA N1.7（Cosmos-Reason2 基于 Qwen3-VL 架构）、上海 AI Lab、优必选 Thinker、原力灵机 DM0（Qwen3-1.7B）| **2026 年最广泛使用的开源具身 VLM 底座** |
| InternVL | 智元 GO-1、上海 AI Lab | 国内开源 |
| Eagle / Cosmos Reason | NVIDIA GR00T | 自研 |
| Llama 2 + Prismatic | OpenVLA | 早期开源 |
| SmolVLM | Hugging Face SmolVLA | 极小 |
| 不用 VLM（视频模型为主干）| NVIDIA DreamZero（Wan2.1-14B）、1XWM（14B 视频模型）| 世界模型派 |
| 从零联合训练 | 自变量 WALL-B（据报道）| 统一模型派 |

**一个关键工程发现**：取 VLM 的**中间层**而非最后一层特征给动作专家（GR00T N1、SmolVLA），往往更快、更好——因为最后几层过度特化于生成文本。

### 3.3 动作表示：机器人大脑的"输出语言"

| 表示方式 | 原理 | 代表 | 优缺点 |
|---|---|---|---|
| **均匀离散 token** | 每维 256 桶 | RT-1、RT-2、OpenVLA | 简单、与 LLM 统一；精度差、慢 |
| **频域压缩 token（FAST）** | DCT + BPE | π0-FAST、π0.5 预训练、G0 阶段一 | 训练快、信息密；推理需解码较多 token |
| **学习式量化（VQ/RVQ）** | VQ-VAE 学习码本 | RDT2（RVQ）、WALL-OSS-0.5（视觉对齐 RVQ）| 紧凑、可学习 |
| **潜在动作** | 从视频相邻帧学习离散码 | GR00T N1（LAPA）、UniVLA、GO-1、XR-1（UVMC）、WholeBodyVLA | **让无标签视频可用** |
| **扩散** | 从噪声迭代去噪 | Diffusion Policy、Octo、RDT、DexVLA、Atlas LBM | 多模态表达力强；步数多 |
| **流匹配** | 学习噪声到动作的速度场 | π0 系列、GR00T、Xiaomi-Robotics-0、GR-3、DM0 | **2025–2026 主流**，步数少、稳定 |
| **连续回归** | MLP 直接回归 | OpenVLA-OFT | 快，但难表达多模态 |
| **与视频联合生成** | 动作作为视频去噪的一个模态 | DreamZero、GR-1/2 | 继承视频物理先验；算力高 |
| **从生成视频反推（IDM）** | 生成未来视频 → 逆动力学 | 1XWM、Vidar、DreamGen | 可利用视频模型；物理一致性风险 |

**2026 年的主流配方**："**离散 token 预训练（FAST/RVQ）让 VLM 学会动作表征 + 流匹配动作专家输出连续动作 + 梯度隔离/桥接保护 VLM 能力**"（π0.5/KI、RDT2、WALL-OSS-0.5、DM0）。

### 3.4 动作分块与实时执行

- **动作分块（Action Chunking）**：一次预测未来 H 步（ACT 100 步、π0 50 步、GR00T 16 步、FiS-VLA 8 步），降低复合误差、表达时间结构（第 11 章）；
- **时间集成 / 滚动时域**：ACT 的时间集成、Diffusion Policy 的 T_o/T_p/T_a 设计（第 15 章）；
- **异步执行**：推理与执行并行——PI 的 RTC、HF SmolVLA 异步推理、Xiaomi-Robotics-0 的"干净动作前缀 + Λ 形注意力掩码"（第 29 章）。

### 3.8 世界模型：四种流派

| 流派 | 原理 | 代表 | 在机器人中的角色 |
|---|---|---|---|
| **像素/视频生成 + 逆动力学** | 生成未来视频，再反推动作 | 1XWM、Vidar、DreamGen | 策略 / 数据生成 |
| **视频-动作联合生成（WAM）** | 动作作为视频去噪的一个模态 | DreamZero / GR00T N2、GR-1/2、WorldVLA | 策略 |
| **视频扩散特征作为表征** | 只取视频模型中间特征，不生成 | VPP（星动纪元）| 策略的视觉主干 |
| **隐式 / 潜空间预测（JEPA 式）** | 在表征空间预测未来，不生成像素 | V-JEPA 2、RoboJEPA（Meta）、Being-H0.7、宇树 WLA（动态区域）| 规划器 / 策略 |
| **动作条件神经模拟器** | 以动作为条件生成未来观察，闭环运行 | 特斯拉神经世界模拟器、Ctrl-World、GE-Sim、LingBot-World、Genie 3、WALL-SS | 评估、数据生成、RL 训练场 |
| **事件级** | 以事件而非帧为单位预测 | 自变量 WALL-WM | 高效策略 / 规划 |

**2026 年的共识**：世界模型在机器人中有**五种用途**——①造数据（Cosmos、GigaWorld-0）②评估策略（1X、Ctrl-World、GE-Sim）③强化学习训练场（AWE 3.5、GigaBrain-0.5M\*、WALL-SS、特斯拉）④生成子目标（π0.7、RxBrain）⑤直接作为策略（DreamZero、1XWM、WRAM）。

### 3.9 全身控制：人形的"小脑与脊髓"

2025–2026 年形成的标准范式是"**动作追踪 + 仿真 RL + 零样本 sim2real**"：
1. **数据**：人类动捕（AMASS、LAFAN1）+ 视频重建动作（HoloMotion、VideoMimic）；
2. **重定向**：保留交互关系的高质量重定向（OmniRetarget）；
3. **训练**：大规模并行仿真 RL，域随机化，特权教师 → 学生蒸馏（H2O）；
4. **sim2real 对齐**：差分动作模型（ASAP）；
5. **提示接口**：行为基础模型（Meta Motivo、BFM-Zero）可被动作、目标、奖励提示；
6. **残差精修**：在通用追踪器上叠加残差策略完成物体交互（ResMimic）；
7. **安全反射**：Agility"运动皮层"、智平方 NeuroVLA 的 SNN 脊髓层。

| 代表 | 机构 | 规模 / 频率 | 训练信号 |
|---|---|---|---|
| Helix 02 S0 | Figure | 约 1000 万参数 / 1kHz | 1000+ 小时人类动作 + RL |

## 八、本章小结：读懂后续 50 章的五把钥匙

1. **语义从哪来**：互联网 VLM（RT-2 以来的共识），但 2026 年出现了"视频模型为母体""从零联合训练"的挑战；
2. **动作怎么生成**：流匹配动作专家是主流，世界模型联合生成是新潮；
3. **数据从哪来**：从遥操作走向人类/无本体数据与部署回流，规模从万小时到百万小时；
4. **如何超越模仿**：RL 后训练、世界模型中训练、部署中持续学习；
5. **如何证明有用**：从演示视频到榜单，再到真实部署的可靠性与吞吐——这是 2027 年的主战场。
